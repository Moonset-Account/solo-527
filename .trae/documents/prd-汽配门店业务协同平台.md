
# 汽配门店业务协同平台 PRD

## 1. 产品概述

面向汽配门店店长及核心岗位的一站式业务协同管理系统，解决车型登记、配件流转、维修派工、质检追溯、订单变更等全流程线上化与数据可视化，取代传统 Excel 导出查看的低效方式。
- 核心目标：将门店从"人记台账"升级为"系统驱动业务协同
- 目标用户：门店店长、仓库管理员、质检员、班组长、前台接待

## 2. 核心功能

### 2.1 用户角色与权限
| 角色 | 注册方式 | 核心权限 |
|--------|----------|----------|
| 门店店长 | 系统后台创建 | 全部功能访问、数据汇总看板、角色权限管理 |
| 仓库管理员 | 系统后台创建 | 配件入库/出库登记、配件周转查询、库存管理 |
| 质检员 | 系统后台创建 | 质检结果录入、质检历史查询 |
| 班组长 | 系统后台创建 | 班组排期、生产节点查询 |
| 前台接待 | 系统后台创建 | 车型登记、维修需求录入、订单变更处理 |

### 2.2 功能模块
1. **工作台（仪表盘）：今日概览、待办任务、数据汇总看板
2. **车辆管理：车型登记、车辆档案、维修需求录入
3. **配件管理：配件登记、配件周转明细、库存查询
4. **维修生产：班组排期、生产节点批量查询
5. **质检中心：质检结果录入、质检历史追溯
6. **订单变更：变更影响分析、责任人追踪、关闭说明
7. **回调监控：外部回调失败记录、补偿操作记录
8. **系统管理：角色权限、用户管理

## 3. 核心流程

### 3.1 车辆入店维修流程
车主到店 → 前台登记车型信息 → 创建维修工单并录入需求 → 仓库分配配件 → 班组长排期派工 → 维修过程节点更新 → 质检员检验 → 工单完成结算

```mermaid
flowchart LR
    A["车主到店" --> B["前台登记车型"]
    B --> C["创建维修工单"]
    C --> D["仓库分配配件"]
    D --> E["班组长排期"]
    E --> F["维修节点更新"]
    F --> G["质检员检验"]
    G --> H["工单完成"]
```

### 3.2 订单变更处理流程
发现变更需求 → 录入变更内容 → 标记影响对象 → 指定责任人 → 处理变更 → 填写关闭说明 → 变更归档

```mermaid
flowchart LR
    A["变更需求"] --> B["录入变更内容"]
    B --> C["标记影响对象"]
    C --> D["指定责任人"]
    D --> E["处理执行"]
    E --> F["填写关闭说明"]
    F --> G["变更归档"]
```

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：工业蓝 #1E3A5F，强调专业稳重的工业风
- 辅助色：琥珀橙 #F59E0B，用于警示和强调
- 中性色：深灰 #1F2937，浅灰 #F3F4F6
- 按钮风格：圆角中等圆角 6px，悬停时轻微阴影
- 字体：Noto Sans SC，中文显示友好
- 布局风格：卡片式布局，顶部导航 + 左侧菜单
- 图标：Lucide Icons，线性风格
- 数据可视化：Recharts 折线图/柱状图

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 工作台 | 数据卡片 | 大数字指标 + 趋势小图 + 图标 |
| 工作台 | 数据汇总图表 | 柱状图展示周数据、折线图趋势 |
| 列表页 | 数据表格 | 斑马条纹、悬浮高亮、行内操作 |
| 表单页 | 表单录入 | 分组卡片、标签、必填标记 |
| 详情页 | 时间线 | 节点进度、操作日志 |

### 4.3 响应式
- 桌面端优先设计，适配 1440px 基准
- 平板端适配 768px 折叠侧边栏
- 移动端最小支持列表视图简化

### 4.4 动效设计
- 页面切换：淡入 + 轻微上移动画
- 卡片悬浮：阴影加深 + 轻微上浮
- 数据加载：骨架屏占位
- 按钮交互：状态颜色过渡 150ms 过渡
