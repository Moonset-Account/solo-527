## 1. 产品概述

同城骑手轨迹看板是面向调度主管的实时运营管理平台，解决同城配送过程中订单调度、骑手轨迹监控、履约时效管理、异常处理等核心业务问题，提升配送效率，降低运营成本。

- 核心目标：为调度主管提供一站式运营管控中心，实现订单全生命周期可视化管理
- 目标用户：调度主管、运营管理人员
- 市场价值：通过实时数据驱动的调度决策，提升同城配送履约率，降低异常赔付率

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|---------|---------|

## 3. 核心流程

### 3.1 订单调度流程

调度主管登录系统后，通过订单管理页面查看待分配订单，根据骑手实时位置和负载情况进行智能调度，骑手接单后可实时监控配送轨迹，确保按时履约。

```mermaid
flowchart LR
    A["新订单进入"] --> B["调度主管查看待分配订单"]
    B --> C["根据骑手位置/负载分配"]
    C --> D["骑手接单"]
    D --> E["实时轨迹监控"]
    E --> F["温控数据采集"]
    F --> G["送达签收"]
    G --> H["履约时效统计"]
    H --> I["异常判定&记录"]
```

### 3.2 异常处理流程

当订单出现超时、温控异常或签收差异时，系统自动触发预警，调度主管介入处理，记录赔付争议原因和处理过程，最终闭环并统计处理时效。

```mermaid
flowchart LR
    A["异常触发"] --> B["系统预警提醒"]
    B --> C["调度主管介入"]
    C --> D["记录争议原因"]
    D --> E["指定处理负责人"]
    E --> F["处理过程追踪"]
    F --> G["异常闭环"]
    G --> H["处理耗时统计"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深空蓝（#0F172A）作为背景主色，工业蓝（#2563EB）作为品牌主色，警示橙（#F97316）用于异常预警，成功绿（#10B981）用于正常状态
- **按钮风格**：直角硬朗风格，2px边框，悬浮时微动画效果
- **字体**：标题使用 Space Grotesk，正文使用 JetBrains Mono，体现工业监控系统的专业感
- **布局风格**：高密度仪表盘布局，模块化卡片设计，顶部导航+侧边栏+主内容区
- **图标风格**：线性简约图标，统一24px尺寸，状态色区分

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 首页仪表盘 | 时效概览 | 大面积数据卡片、环形进度图、趋势折线图、微动画数值滚动 |
| 首页仪表盘 | 筛选栏 | 下拉选择器、日期范围选择、状态标签组、责任人搜索 |
| 订单管理 | 订单列表 | 表格视图、行内操作按钮、状态色标签、优先级标识 |
| 订单管理 | 路线地图 | 交互式地图、路线高亮、途经点标记、距离时长估算 |
| 轨迹监控 | 实时地图 | 骑手位置标记、轨迹线绘制、实时刷新动画、区域热力图 |
| 轨迹监控 | 温控面板 | 温度曲线图、阈值警戒线、异常闪烁效果、历史数据切换 |
| 异常管理 | 异常列表 | 时间轴布局、争议原因标签、处理耗时进度条、负责人头像 |
| 数据查询 | 多维度表格 | 可排序表头、分页器、行展开详情、数据高亮对比 |

### 4.3 响应式

- 桌面端优先设计，最小支持1440px宽度
- 平板端自适应布局，侧边栏可收起
- 移动端简化视图，核心数据卡片优先展示
- 表格支持横向滚动，触屏友好的操作按钮尺寸

### 4.4 数据可视化

- **地图组件**：集成Leaflet实现骑手轨迹可视化
- **图表组件**：使用Recharts绘制时效趋势、温度曲线
- **实时更新**：WebSocket推送实现秒级数据刷新
- **动效设计**：数据更新时平滑过渡动画，异常状态脉冲闪烁效果
