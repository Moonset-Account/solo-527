## 1. 产品概述

内容安全运营短视频内容审核积压看板，面向内容安全运营团队，实时监控审核队列积压状态、人审效率、申诉质量，通过多维度下钻分析定位审核瓶颈与风险标签分布。

- 解决问题：审核队列积压不可视、风险标签与申诉结果关联断裂、审核员负载不均衡
- 目标用户：内容安全运营经理、审核组长、数据分析人员
- 产品价值：缩短积压告警响应时间，优化审核资源调配，提升申诉逆转分析精度

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 运营管理员 | SSO单点登录 | 查看全量看板、导出数据、配置指标口径 |
| 审核组长 | SSO单点登录 | 查看本组数据、管理班次配置 |
| 数据分析师 | SSO单点登录 | 全维度下钻、自定义筛选、导出原始数据 |

### 2.2 功能模块

1. **异常摘要区**：顶部异常告警卡片，实时展示积压突增、SLA破线、申诉逆转率异常等核心问题
2. **多维筛选区**：支持按风险标签、队列类型、审核员、班次、视频来源切换分析视角
3. **积压曲线视图**：时序折线图展示各队列积压量趋势与SLA阈值线
4. **队列漏斗视图**：桑基/漏斗图展示机器初筛 → 人审队列 → 审核结果 → 申诉流程的转化
5. **审核员负载视图**：热力图+柱状图展示审核员处理量、平均时长、积压量分布
6. **申诉逆转率视图**：条形图按原风险标签维度统计申诉成功率，关联原始标签而非最终状态
7. **数据导出**：支持按筛选上下文导出CSV/Excel报表

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主看板 | 异常摘要卡片 | 实时计算积压增长率、SLA违规率、申诉逆转率异常波动，红色高亮告警 |
| 主看板 | 维度筛选器 | 标签多选、队列单选、审核员多选、班次单选、来源多选，级联联动 |
| 主看板 | 积压趋势曲线 | Plotly多线折线图，支持缩放、hover详情、SLA阈值参考线 |
| 主看板 | 队列转化漏斗 | Plotly漏斗图/Sankey图，展示各环节转化率与停留时长 |
| 主看板 | 审核员负载矩阵 | 按班次×审核员的热力图，点击下钻单人详情 |
| 主看板 | 申诉逆转分析 | 按原机器风险标签分组，展示申诉成功/失败占比，识别误判高发标签 |
| 主看板 | 筛选上下文保留 | URL参数同步筛选状态，刷新页面不丢失，支持分享链接 |

## 3. 核心流程

### 3.1 用户操作流程

运营人员进入看板 → 自动加载近24小时全局异常摘要 → 发现某风险标签积压突增 → 点击该标签筛选 → 查看对应队列积压曲线与审核员负载 → 切换班次维度查看人员分配 → 导出该标签下申诉逆转明细 → 调整次日审核排班

```mermaid
flowchart LR
    A["进入看板"] --> B["加载异常摘要"]
    B --> C["发现积压告警"]
    C --> D["点击标签筛选"]
    D --> E["查看积压曲线"]
    E --> F["切换审核员/班次维度"]
    F --> G["下钻申诉逆转详情"]
    G --> H["导出报表"]
    H --> I["优化排班策略"]
```

### 3.2 数据流转流程

原始审核日志 → 数据清洗脚本 → TimescaleDB时序库 → 聚合API层 → Redis缓存 → Dash前端渲染

```mermaid
flowchart LR
    A["原始日志Kafka"] --> B["清洗脚本Python"]
    B --> C["TimescaleDB"]
    C --> D["聚合API"]
    D --> E["Redis缓存"]
    E --> F["Dash + Plotly"]
    F --> G["用户浏览器"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深空灰 (#1a1a2e) 为背景，科技蓝 (#16213e) 为卡片底色，告警红 (#e94560) 高亮异常，数据绿 (#0f3460) 标识正常
- **辅助色**：琥珀橙 (#f39c12) 表示警告状态，薄荷绿 (#2ecc71) 表示达标
- **按钮风格**：扁平化圆角按钮，hover时有轻微上浮阴影，选中态有蓝色底边高亮
- **字体**：标题使用 'JetBrains Mono' 等宽字体增强数据感，正文使用 'Inter' 确保可读性
- **布局风格**：卡片式网格化布局，卡片带细微边框与柔光阴影，非对称信息密度分布
- **图标风格**：线性图标，统一2px描边，配色与功能语义一致

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主看板 | 异常摘要区 | 4张告警卡片横向排列，异常卡片红色脉动动画，数字大号加粗 |
| 主看板 | 筛选区 | 下拉选择器+标签面包屑，横向排列，已选项显示为可删除标签 |
| 主看板 | 积压曲线图 | 深色背景，网格线半透明，多色折线，hover十字准星 |
| 主看板 | 漏斗图 | 渐变色填充漏斗，hover显示各层绝对值与转化率 |
| 主看板 | 审核员热力图 | 网格色块，颜色深浅映射负载值，点击行高亮 |
| 主看板 | 申诉逆转条形图 | 分组条形图，原风险标签为横轴，申诉成功/失败堆叠 |

### 4.3 响应式

- 桌面端优先：1920×1080为基准设计，支持2560宽屏扩展
- 平板适配：卡片自动换行，图表缩小比例
- 大屏监控：支持全屏模式（F11），隐藏筛选栏仅保留核心图表

### 4.4 交互动效

- 页面加载：卡片依次淡入，延迟50ms错位
- 图表切换：Plotly自带过渡动画，duration 300ms
- 告警卡片：异常状态下边框呼吸灯效果（opacity 0.6-1 循环）
- 筛选联动：选中筛选器后图表平滑重绘
