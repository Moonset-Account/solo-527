## 1. 产品概述

销售经营异常监控台是面向销售总监的智能监控平台，实时追踪销售核心指标的异常波动，提供告警推送、原因分析和处理追踪，帮助销售团队快速发现问题、定位原因、闭环处理，保障销售目标达成。

- 核心用户：销售总监、销售经理、数据运营
- 核心价值：异常早发现、原因快定位、处理有追踪、复盘有依据

## 2. 核心功能

| 角色 | 注册方式 | 核心权限 |
|------|---------|---------|
| 销售总监 | Clerk SSO | 全功能权限、告警规则配置、报表查看、口径变更审批 |
| 销售经理 | Clerk SSO | 异常查看、处理结果填写、个人维度数据 |

5. **系统设置**：权限管理、指标字典、数据安全配置

## 3. 核心流程

### 3.1 告警配置流程

销售总监进入告警规则页面，选择需要监控的指标（如销售额、订单量），设置时间范围（如日、周、月），配置告警阈值（如环比下降超过10%），选择告警渠道（站内信、邮件、企业微信），保存后规则生效，系统自动检测异常并触发告警。

```mermaid
flowchart LR
    A["进入告警规则"] --> B["选择监控指标"]
    B --> C["设置时间范围"]
    C --> D["配置告警阈值"]
    D --> E["选择告警渠道"]
    E --> F["保存生效"]
```

### 3.2 异常处理流程

系统检测到指标异常后生成告警，推送至相关人员。销售总监或经理查看异常详情，结合指标口径和趋势分析原因，填写处理记录和解决方案，异常状态更新为处理中或已关闭。处理记录自动写入报表，供月底复盘使用。

```mermaid
flowchart LR
    A["系统检测异常"] --> B["生成告警并推送"]
    B --> C["查看异常详情"]
    C --> D["分析原因（同屏看口径）"]
    D --> E["填写处理结果"]
    E --> F["异常关闭/归档"]
    F --> G["自动写入报表"]
```

### 3.3 口径变更流程

数据运营提交指标口径变更申请，系统自动提醒销售总监审批。总监查看变更前后对比，确认后生效。所有变更记录记入日志，报表中标记口径变更时间点，确保月底复盘时数据可追溯。

```mermaid
flowchart LR
    A["提交口径变更"] --> B["自动提醒销售总监"]
    B --> C["查看变更对比"]
    C --> D["审批确认"]
    D --> E["口径生效并记录日志"]
    E --> F["报表标记变更点"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝 #1E3A5F 作为主色，传达专业和信任感
- **辅助色**：琥珀橙 #F59E0B 用于告警提示，翠绿 #10B981 用于正常状态，玫红 #EF4444 用于严重异常
- **中性色**：深灰 #1F2937 正文，中灰 #6B7280 次要文字，浅灰 #F3F4F6 背景
- **按钮风格**：圆角 8px，悬停时有微妙的阴影和颜色加深效果
- **字体**：标题使用 Noto Sans SC Bold，正文使用 Noto Sans SC Regular，数字使用等宽字体提升可读性
- **布局风格**：卡片式布局，清晰的信息层级，重点数据突出展示
- **图标风格**：线性图标，统一 24px 尺寸，颜色与功能状态对应

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 监控看板 | 指标概览卡片 | 大字号数字 + 趋势箭头 + 同比环比标签，卡片悬浮有阴影效果 |
| 监控看板 | 异常趋势图 | 面积图 + 柱状图组合，异常点用红色圆点标记 |
| 监控看板 | 活跃告警列表 | 列表项左对齐严重程度色条，右对齐时间，悬停高亮 |
| 监控看板 | 指标口径侧栏 | 可展开抽屉式设计，半透明背景遮罩，滑入动画 |
| 告警规则 | 规则列表 | 表格布局，开关按钮，操作列悬停显示 |
| 告警规则 | 配置向导 | 步骤指示器，分步表单，进度动画 |
| 异常中心 | 异常列表 | 筛选栏固定顶部，列表卡片式，支持批量操作 |
| 异常中心 | 异常详情 | 左右分栏布局，左侧数据图表，右侧原因分析和处理记录 |
| 报表复盘 | 月度报表 | 分章节展示，数据表格 + 图表结合，可折叠区块 |
| 系统设置 | 权限管理 | 角色卡片 + 权限树，拖拽或勾选配置 |

### 4.3 响应式

- 桌面端优先设计（1440px 基准）
- 平板端（768px-1024px）：侧栏折叠为图标模式，内容区自适应
- 移动端（<768px）：底部导航栏，卡片单列布局，重点信息前置
- 移动端核心功能：异常查看、筛选、处理结果填写
- 触摸优化：按钮最小尺寸 44px，列表项点击区域扩大

### 4.4 动效设计

- 页面加载：内容淡入 + 轻微上移，错峰出现
- 数据更新：数字滚动动画，图表重绘过渡
- 告警出现：右侧滑入 + 轻微弹跳，红色呼吸灯效果
- 抽屉展开：平滑滑入 + 背景遮罩淡入
- 按钮交互：点击时缩放 0.98，松开回弹
