## 1. 产品概述

电商售后退货原因与退款周期分析工作台——面向售后负责人的交互式看板，聚焦退货原因归因、退款周期监控和异常样本追溯。不同于静态报表，它提供多维联动筛选、下钻分析和口径可溯的导出能力，帮助售后团队从宏观趋势定位到单条异常订单。

- 解决问题：售后负责人缺乏一站式工具同时查看退货原因分布、退款周期瓶颈和客服处理效率，数据分散且口径不统一
- 目标用户：电商平台售后负责人、售后运营分析师、客服主管

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 售后负责人 | 管理员分配账号 | 查看全部数据、导出含隐私字段报告、标注异常点 |
| 售后分析师 | 管理员分配账号 | 查看脱敏数据、导出脱敏报告、下钻分析 |
| 客服主管 | 管理员分配账号 | 查看本组数据、客服处理时长分析 |

### 2.2 功能模块

1. **分析工作台主页**：全局筛选器 + 四大核心图表 + 数据概览卡片 + 数据更新时间提示
2. **退货原因下钻页**：原因树图 → 原因明细 → 异常样本列表
3. **退款周期分析页**：周期分布直方图 + 各环节耗时分解 + 物流商对比
4. **商品排行与异常页**：商品退货率排行 + 重复退货用户识别（脱敏）+ 异常点标注
5. **导出任务管理页**：导出任务队列 + 导出文件下载（含筛选条件与样本量元信息）
6. **数据管理页**：批量导入 + 数据字典 + 口径配置 + 缺失值处理规则

## 3. 核心流程

### 3.1 售后分析主流程

售后负责人登录 → 进入分析工作台 → 查看全局概览 → 选择筛选维度（商品/店铺/原因/仓库/物流商）→ 图表联动更新 → 发现异常（如某原因退货激增）→ 点击下钻到原因树 → 查看异常样本明细 → 标注异常点 → 导出含元信息报告

### 3.2 数据流转流程

原始订单/退货数据 → ETL 清洗脚本 → 口径校验 → 写入 PostgreSQL → 缓存层 → API → 前端图表渲染

```mermaid
flowchart TD
    "原始数据源" --> "ETL 清洗脚本"
    "ETL 清洗脚本" --> "口径校验"
    "口径校验" --> "PostgreSQL/PostGIS"
    "PostgreSQL/PostGIS" --> "缓存层(Redis/内存)"
    "缓存层(Redis/内存)" --> "API 服务"
    "API 服务" --> "前端 ECharts 渲染"
    "API 服务" --> "导出任务队列"
    "导出任务队列" --> "CSV/PDF 文件"
    "前端 ECharts 渲染" --> "用户交互下钻"
    "用户交互下钻" --> "API 服务"
```

### 3.3 导出流程

用户选择导出格式 → 系统记录当前筛选条件快照 + 样本量 + 数据更新时间 → 创建异步导出任务 → 生成文件（表头含元信息行）→ 任务完成通知 → 用户下载

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝灰（#1e293b）为底，翠绿（#10b981）为强调色，橙红（#ef4444）为异常警示色
- 次色调：浅灰（#f1f5f9）卡片背景，白（#ffffff）图表区域
- 按钮风格：圆角 8px，主按钮填充色，次按钮描边
- 字体：思源黑体（Noto Sans SC）为主体，等宽字体为数据展示
- 布局风格：左侧固定筛选面板 + 右侧自适应图表区，顶部全局导航和状态栏
- 图标风格：Lucide 线性图标，2px 描边

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1280px
- 图表区域自适应容器宽度
- 筛选面板可折叠收起
- 表格横向滚动

### 4.4 地理空间场景指引（Mapbox GL + PostGIS）

- 地图用于展示退货订单的地理分布热力图
- 仓库位置标注和退货来源区域映射
- 物流商路线可视化
- 交互：缩放、点击区域下钻、hover 显示统计摘要
- 地图仅作为辅助视图，不替代核心图表分析
