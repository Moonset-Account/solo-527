## 1. 产品概述

北桥房态行程台是一款面向精品民宿的房态库存管理平台，解决民宿运营中房态不透明、库存不同步、待办无追踪的核心痛点。目标用户为民宿住客（查询房态并下单）和民宿运营团队（管理库存、清洁、待办与报表）。产品价值在于提升入住转化率、降低空置率、实现运营全链路数字化。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 住客 | 手机号注册/微信授权 | 浏览房态、下单、退款申请、提交评价 |
| 运营负责人 | 后台分配账号 | 房态管理、库存同步、待办处理、报表导出 |
| 清洁人员 | 后台分配账号 | 查看待办清洁任务、更新清洁状态 |
| 管理员 | 后台分配账号 | 全部权限、人员管理、提醒规则配置 |

### 2.2 功能模块

1. **用户侧首页**: 房态日历视图、房型筛选、快速下单入口
2. **房间详情页**: 房型介绍、实时房态、价格日历、评价列表
3. **订单中心**: 下单流程、订单状态跟踪、退款申请
4. **管理仪表盘**: 房态总览、空置率看板、待办汇总、提醒中心
5. **房态管理页**: 房态日历编辑、库存同步操作、批量更新
6. **待办中心**: 待办列表（退款审批/清洁任务/评价回复）、分级提醒、办结更新空置率
7. **报表导出页**: 入住转化统计、筛选条件留存、导出带口径与操作者

## 3. 核心流程

### 3.1 住客下单流程
住客打开首页 → 选择入住/离店日期 → 浏览可订房型 → 选择房型进入详情 → 填写入住信息 → 提交订单 → 支付确认 → 订单成立 → 入住/退款

### 3.2 房态同步流程
管理员进入房态管理 → 查看/编辑房态日历 → 修改库存数量 → 触发渠道同步 → 同步结果写入日志 → 库存变化触发提醒规则 → 推送提醒到负责人

### 3.3 待办处理流程
事件触发（退款申请/退房/新评价）→ 系统生成待办 → 按规则匹配负责人 → 分级推送提醒 → 负责人处理待办 → 办结更新空置率 → 记录操作日志

### 3.4 提醒规则流程
库存变动 → 检查提醒规则阈值 → 匹配影响等级 → P0紧急：立即推送+标红 → P1重要：推送+标橙 → P2一般：汇总推送 → 负责人处理 → 提醒标记已读

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**: 深松绿 (#1B4332) + 暖米白 (#FEFAE0)，营造精品民宿的质感与温暖
- **辅助色**: 琥珀金 (#D4A373) 作为强调色，砖红 (#BC4749) 作为警示色
- **按钮风格**: 圆角按钮（8px），主要操作深松绿底白字，次要操作白底深松绿边框
- **字体**: 标题使用 Noto Serif SC（衬线体体现精品感），正文使用 Noto Sans SC
- **布局风格**: 左侧固定导航栏 + 右侧内容区，卡片式布局
- **图标风格**: 线性图标，2px 描边，与整体风格统一

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 用户侧首页 | 房态日历视图 | 日历网格布局，可订日期深松绿底色，已满灰色，悬停显示价格气泡；顶部日期范围选择器 |
| 用户侧首页 | 房型卡片列表 | 横向滚动卡片，每张卡片含房型图片、名称、最低价、可订标签 |
| 房间详情页 | 实时房态面板 | 左侧价格日历（月视图），右侧房型图文介绍与设施标签 |
| 房间详情页 | 评价列表 | 卡片式评价，含评分星标、头像、评价内容、图片缩略图 |
| 订单中心 | 订单列表 | 表格式布局，状态标签色彩区分，操作按钮右对齐 |
| 管理仪表盘 | 房态总览 | 网格式房态看板，每格一个房间，颜色编码状态 |
| 管理仪表盘 | 空置率看板 | 折线图+数值卡片，趋势对比 |
| 待办中心 | 待办列表 | 列表式布局，左侧优先级色条（红/橙/蓝），右侧操作按钮 |
| 待办中心 | 分级提醒 | 顶部提醒横幅（P0红色/P1橙色/P2蓝色），支持展开详情 |
| 报表导出页 | 统计图表 | 柱状图+饼图组合，上方筛选栏，下方数据表格 |
| 报表导出页 | 导出面板 | 侧边抽屉式导出配置，含筛选口径摘要、操作者信息、生成时间 |

### 4.3 响应式设计

- 桌面优先设计，管理侧以 1440px 基准宽度
- 用户侧适配移动端（375px+），日历视图在移动端切换为列表模式
- 触控优化：按钮最小点击区域 44px，日历格子最小 40px

### 4.4 状态字段设计

| 状态字段 | 可选值 | 用途 |
|----------|--------|------|
| 房间状态 | 可售/已预订/已入住/维护中/清洁中 | 筛选+提醒+报表 |
| 订单状态 | 待支付/已支付/已入住/已退房/退款中/已退款/已取消 | 筛选+提醒+报表 |
| 清洁状态 | 待清洁/清洁中/已完成 | 筛选+待办 |
| 评价状态 | 待回复/已回复 | 筛选+待办 |
| 提醒等级 | P0紧急/P1重要/P2一般 | 提醒分级+报表 |
| 待办状态 | 待处理/处理中/已办结 | 筛选+报表 |
| 库存同步状态 | 未同步/同步中/已同步/同步失败 | 筛选+提醒 |
