## 1. 产品概述

家庭预算与消费结构分析工作台——面向个人理财爱好者的交互式分析工作台，而非静态报表。用户可在此追踪收入、固定支出、订阅、购物、旅行和信用卡账单，通过多维度联动筛选快速洞察消费结构、预算执行进度与异常消费，同时支持家庭成员协作与隐私保护。

- 核心价值：让家庭理财从"看报表"升级为"做分析"，通过联动筛选、下钻、异常检测实现主动式财务管理
- 目标用户：有家庭协作需求的个人理财爱好者，具备一定数据敏感度

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 家庭管理员 | 邀请注册 | 管理共享分类规则、查看所有成员汇总、导出报告 |
| 家庭成员 | 邀请注册 | 使用共享分类规则、查看个人明细、隐藏个人账户 |
| 个人用户 | 自由注册 | 全部个人功能、无家庭协作 |

### 2.2 功能模块

1. **分析工作台（主页）**：筛选栏、预算进度面板、分类占比图、现金流图、订阅提醒面板、异常样本面板
2. **分类规则管理页**：家庭共享规则编辑、个人规则覆盖、规则优先级

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 分析工作台 | 全局筛选栏 | 按账户、分类、成员、月份、商户快速切换，筛选状态贯穿所有图表与导出 |
| 分析工作台 | 预算进度面板 | 各分类预算 vs 实际进度条，超支预警高亮，支持点击下钻 |
| 分析工作台 | 分类占比图 | D3 环形图展示消费结构，点击扇区联动筛选，支持多级分类 |
| 分析工作台 | 现金流图 | D3 面积图展示月度收入/支出趋势，叠加净现金流线 |
| 分析工作台 | 订阅提醒面板 | 即将续费/扣款列表，含金额、日期、账户，一键标记处理 |
| 分析工作台 | 异常样本面板 | 基于口径配置检测的消费异常，支持过滤/排除后刷新统计 |
| 分析工作台 | 数据状态栏 | 显示数据更新时间、当前筛选条件摘要、有效样本量 |

| 分类规则管理 | 隐私开关 | 控制个人账户明细在家庭视图中是否可见 |

## 3. 核心流程

**主分析流程**：用户进入工作台 → 选择筛选维度（账户/分类/成员/月份/商户）→ 图表联动刷新 → 点击图表元素下钻 → 发现异常样本 → 过滤异常后重新计算 → 导出带元信息的分析报告

**分类规则协作流程**：家庭管理员创建共享规则 → 成员自动继承 → 成员可添加个人规则覆盖 → 隐私开关控制可见性

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深墨绿 (#0D1F2D) 为底，搭配翡翠绿 (#00C9A7) 作为强调色，传达专业金融感
- **辅助色**：暖琥珀 (#FFB347) 用于预警/超支，珊瑚红 (#FF6B6B) 用于异常，冰蓝 (#4ECDC4) 用于正向指标
- **按钮风格**：圆角 8px，微投影，悬停时亮度提升 + 微缩放
- **字体**：标题使用 DM Serif Display（衬线，金融质感），正文使用 DM Sans（现代无衬线，高可读性）
- **布局风格**：左侧筛选栏 + 右侧自适应网格卡片，卡片间有呼吸感间距
- **图标风格**：线性图标 (Lucide)，2px 描边，统一绿色调

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 分析工作台 | 全局筛选栏 | 顶部固定栏，多选下拉框，标签式已选条件，清空按钮 |
| 分析工作台 | 预算进度面板 | 水平进度条组，超支条目红色渐变，预算/实际金额标注 |
| 分析工作台 | 分类占比图 | D3 环形图，中心显示总额，扇区 hover 高亮，图例可点击联动 |
| 分析工作台 | 现金流图 | D3 堆叠面积图，收入绿色/支出橙色/净流蓝色虚线，时间轴可缩放 |
| 分析工作台 | 订阅提醒面板 | 列表卡片，续费倒计时徽章，金额突出，滑动标记已处理 |
| 分析工作台 | 异常样本面板 | 表格形式，异常类型标签（金额异常/频率异常/商户异常），复选框排除 |
| 分析工作台 | 数据状态栏 | 底部固定栏，更新时间戳、筛选条件摘要、样本量计数器 |
| 分类规则管理 | 规则表 | 可编辑表格，拖拽排序优先级，共享/个人标签区分 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1280px 完整展示
- 平板端（768-1279px）筛选栏折叠为顶部抽屉，卡片单列
- 移动端（< 768px）仅展示核心摘要卡片，筛选为底部弹出面板

### 4.4 3D 场景指引

- 不适用，本项目为 2D 数据可视化工作台
