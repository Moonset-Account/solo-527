## 1. 产品概述

宿舍报修审核后台系统——面向高校宿管团队的一站式报修受理、身份审核、自习室座位管理与流转追踪平台。解决传统纸质/碎片化报修流程中信息丢失、审核无追溯、处理效率不透明等核心痛点，为宿管老师和运营团队提供高效的数字化管理工具。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 学生 | 学号注册 | 提交报修申请、上传照片、查看申请进度、签到 |
| 宿管老师 | 管理员分配 | 审核报修、分配名额、管理签到、查看流转记录 |
| 运营管理员 | 系统内置 | 全量数据管理、批量操作、导出报表、效率监控 |

### 2.2 功能模块

1. **报修申请页**：申请表单、照片上传、进度跟踪、消息通知
2. **审核管理页**：报修审核列表、身份审核、名额分配、签到管理
3. **流转记录页**：完整状态变更历史、身份审核前后变化、座位分配变化、报修处理过程
4. **明细导出页**：座位利用率统计、身份审核失败明细、处理记录汇总、条件筛选、批量导出
5. **批量处理页**：批量审核确认、失败项独立展示、重试入口、二次确认弹窗

## 3. 核心流程

### 3.1 报修申请与审核流程

学生提交报修申请 → 系统生成申请单 → 宿管老师审核 → 身份核验 → 名额检查 → 分配处理人 → 处理维修 → 完结确认

```mermaid
flowchart TD
    "学生提交报修申请" --> "系统生成申请单(待审核)"
    "系统生成申请单(待审核)" --> "宿管老师审核"
    "宿管老师审核" --> "身份核验"
    "身份核验" -->|"通过"| "名额检查"
    "身份核验" -->|"失败"| "记录失败原因, 通知学生"
    "名额检查" -->|"有名额"| "分配处理人"
    "名额检查" -->|"无名额"| "进入候补队列"
    "分配处理人" --> "处理维修"
    "处理维修" --> "完结确认"
    "完结确认" --> "记录流转, 更新明细"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝灰 (#1e293b) 搭配明快蓝 (#3b82f6) 强调色，传递专业与高效
- **辅助色**：成功绿 (#10b981)、警告橙 (#f59e0b)、错误红 (#ef4444)
- **按钮风格**：圆角微凸（rounded-lg + shadow-sm），主操作实色填充，次要操作描边
- **字体**：标题使用 Noto Sans SC Bold，正文使用 Noto Sans SC Regular
- **布局风格**：左侧固定导航栏 + 右侧内容区，卡片式模块布局
- **图标风格**：Lucide 线性图标，统一 20px 尺寸

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1280px
- 平板端（768px-1280px）：侧边栏折叠为图标模式，表格简化列数
- 移动端（<768px）：底部导航栏替代侧边栏，卡片堆叠布局
