## 1. 产品概述

青禾租户服务台是面向产业园区的日常运营管理工具，将租户费用账单、服务申请、工程报修、巡检异常等分散流程统一收口。系统核心价值在于：所有业务单据保留原始附件与备注，服务响应可按时间回看，变更记录可按字段追溯，支撑业务复盘与审计需求。

- 目标用户：产业园运营团队、管理台管理员、园区租户
- 核心场景：账单生成与归档、服务申请闭环、巡检异常跟踪、变更审计追溯

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 管理台管理员 | Clerk 后台邀请 | 生成账单、审批服务申请、管理房态价格、查看全部变更记录 |
| 园区运营人员 | Clerk 后台邀请 | 提交服务申请、提交工程报修、记录巡检、查看负责范围内的数据 |
| 租户联系人 | Clerk 邀请注册 | 查看本租户账单、提交服务申请、查看租户档案 |

### 2.2 功能模块

1. **工作台**：关键指标卡片、待办事项、近期动态
2. **租户档案**：租户基本信息、合同信息、附件归档、备注
3. **房态管理**：房间状态看板、价格设置、入住/退租操作
4. **服务申请**：提交申请、流转状态、响应时间回看、附件与备注
5. **费用账单**：账单生成、费用明细、支付状态、原始单据附件
6. **工程报修**：报修工单提交、处理流程、完成归档、附件保留
7. **巡检管理**：巡检计划、巡检记录、异常登记（影响对象/处理人/后续动作）
8. **变更记录**：按字段筛选的审计日志、变更前后值对比、操作人追溯

## 3. 核心流程

### 3.1 服务申请闭环

运营人员提交服务申请 → 管理台审批 → 分配处理人 → 处理完成 → 归档（保留全部附件与备注）→ 可按时间回看每一步的响应时长

### 3.2 账单生成流程

选择租户与房间 → 录入费用项（租金/物业/水电等）→ 自动汇总生成账单 → 关联原始单据附件 → 发送给租户 → 跟踪支付状态

### 3.3 巡检异常处理

执行巡检计划 → 发现异常 → 登记异常记录（影响对象/当前处理人/后续动作）→ 跟踪至闭环 → 全程保留变更记录

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深松绿 #1A3C34（稳重、专业、呼应"青禾"品牌）
- **辅助色**：暖琥珀 #D4A853（用于强调按钮、关键指标、状态高亮）
- **背景色**：暖米白 #F8F6F0（避免纯白的冰冷感）
- **卡片色**：#FFFFFF 带微妙绿色左边框
- **危险色**：#C0392B（逾期、异常等警示）
- **成功色**：#27AE60（完成、已支付等正向状态）
- **按钮风格**：圆角 8px，主按钮深松绿底白字，次要按钮白底绿边
- **字体**：标题使用 Noto Serif SC（衬线体增添文化感），正文使用 DM Sans（清晰易读）
- **布局风格**：左侧固定导航栏 + 右侧内容区，内容区采用卡片式布局
- **图标风格**：线性图标，Stroke 1.5px，与整体简洁风格一致

### 4.3 响应式策略

- 桌面优先设计，最小适配 1280px 宽度
- 侧边栏在 1024px 以下自动折叠为图标模式
- 表格在小屏下切换为卡片视图
- 移动端提供关键操作入口（查看账单、提交报修）
