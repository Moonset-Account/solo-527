## 1. 产品概述

设计图纸项目管理台是一款面向装修设计行业的项目全流程管控系统。核心解决设计师确认报价/增项效率低、预算异常无法追溯责任人、客户投诉通知不及时、合同风险月底复盘缺乏数据支撑等痛点。

- **目标用户**：设计师（值班核对）、项目经理（阶段维护）、管理员（全局监控）、装修公司老板（投诉通知）
- **核心价值**：将散落在二级页面的巡检/验收/方案信息提升至首屏可见，预算异常自动定位责任人，投诉高优自动通知老板，合同风险沉淀到月度报表，所有金额/状态/负责人变更保留完整历史对比

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|---------|---------|
| 设计师 | Clerk 邮箱注册 | 确认报价/增项、查看巡检/验收/方案、提交巡检/验收结果 |
| 项目经理 | 管理员分配 | 维护项目阶段、记录预算变更、录入投诉和风险 |
| 管理员 | 系统预设 | 全部权限、用户管理、月度报表 |
| 装修公司老板 | Clerk 邮箱注册 | 接收高优投诉通知、查看关联项目风险 |

### 2.2 功能模块

1. **工作台总览**：首屏展示待巡检任务、验收反馈、装修方案、预算异常预警、客户投诉——设计师值班核心信息全在一屏
2. **项目列表**：全项目搜索筛选，预算进度条/预警/待办概览
3. **项目详情**：8 个标签页覆盖报价/增项、阶段、巡检/验收/方案、预算变更、投诉、合同风险、历史对比
4. **报价/增项确认**：设计师专属页，待确认报价单和增项快速操作
5. **阶段维护**：内部后台，选择项目维护阶段和状态
6. **预算监控**：异常项目列表+责任人定位，全量预算变更历史
7. **投诉/风险**：投诉管理+合同风险录入，高/紧急自动通知老板
8. **月度报表**：合同风险汇总、投诉统计、预算异常分析，月底复盘专用

## 3. 核心流程

### 3.1 设计师值班核对流程

设计师登录后在工作台总览页直接看到：
1. 待巡检任务列表 → 点击项目进入详情处理
2. 验收反馈卡片 → 查看整改项和反馈
3. 装修方案卡片 → 核对当前版本方案

无需进入项目详情的二级标签页即可完成值班核心任务。

### 3.2 预算异常追踪流程

预算变更被记录时：
1. 系统自动判断变更率是否超 10% 或预算低于实际成本 → 标记异常
2. 异常项在总览、预算监控页一级展示，高亮责任人
3. 项目详情的预算变更标签可追溯完整变更链

### 3.3 投诉处理流程

录入投诉时：
1. 优先级选 HIGH 或 URGENT → 自动设置 bossNotified=true，记录通知时间
2. 手动点击"通知老板"按钮也可触发通知
3. 合同风险同步录入 → 按月汇总到月度报表供复盘

### 3.4 历史对比流程

任何金额/状态/负责人变更：
1. 系统自动写入 ChangeHistory 表，记录旧值、新值、操作人、责任人
2. 项目详情"历史对比"标签页展示变更前后对比卡片
3. 金额变更黄色标记、状态变更蓝色标记、负责人变更紫色标记

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝灰 (#1a1f2e) 为主色，搭配琥珀金 (#d4a853) 作为强调色，传达专业与信赖感
- **次色调**：冷灰 (#64748b) 辅助信息，白色 (#ffffff) 背景保持清爽
- **按钮风格**：圆角 6px，主按钮深蓝灰实心，次按钮描边，危险按钮暗红
- **字体**：正文使用 DM Sans（清晰专业），标题使用 Space Grotesk（几何现代感）
- **布局风格**：左侧固定导航 + 右侧内容区，卡片式布局，表格辅助
- **图标**：使用 Lucide 线性图标替代 emoji，提升专业感
- **风格方向**：工业仪表盘（Industrial Dashboard）——精密仪表感、数据密度高、层次分明

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 工作台总览 | 统计卡片行 | 深色卡片、琥珀色数值、Lucide 图标 |
| 工作台总览 | 核心信息三栏 | 巡检/验收/方案/投诉各占卡片，数据直接展示不折叠 |
| 工作台总览 | 预算异常 | 红色边框卡片、异常金额高亮、责任人头像 |
| 工作台总览 | 项目概览 | 紧凑表格、预算进度条、状态标签 |
| 项目列表 | 搜索筛选栏 | 搜索输入框+状态下拉并排 |
| 项目详情 | 标签页导航 | 水平标签栏，当前标签下划线强调 |
| 项目详情 | 历史对比 | 时间线+变更前后对比卡片（红/绿底色） |

| 投诉/风险页 | 投诉卡片 | 优先级彩色标签、老板通知徽章 |
| 月度报表 | 风险等级矩阵 | 四色方块统计+明细表格 |

### 4.3 响应式

- 桌面优先设计，最小宽度 1280px
- 中等屏幕（1024-1279px）：统计卡片从 5 列变为 3 列
- 移动端暂不优化，仅保证不严重错乱
