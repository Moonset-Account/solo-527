## 1. 产品概述

医院药房取药瓶颈分析运营复盘平台，面向药房运营改善组，通过多维度对比处方全流程数据，识别取药瓶颈并支持下钻分析与人工备注，持续优化药房运营效率。

- 目标用户：医院药房运营改善组、药剂科管理人员
- 核心价值：通过数据可视化快速定位取药流程瓶颈，支撑运营决策，缩短患者取药等待时间

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 运营改善专员 | 内部账号 | 查看数据、下钻明细、添加备注 |
| 药剂科主任 | 内部账号 | 全部权限、导出报告 |

### 2.2 功能模块

1. **总览仪表盘**：核心指标概览、趋势对比、异常预警
2. **流程瓶颈分析**：桑基图展示全流程流转、瓶颈识别
3. **多维度对比分析**：按窗口/药师/科室/处方类型/时段对比
4. **明细表下钻**：从汇总数据下钻至原始处方记录
5. **人工备注系统**：对异常数据点添加备注说明

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|----------|
| 运营复盘总览 | KPI指标卡 | 展示平均等待时长、处方量、配药效率、退药率等核心指标，支持急诊/普通处方分开统计 |
| 运营复盘总览 | 等待时长分布 | 直方图展示患者取药等待时长分布情况 |
| 运营复盘总览 | 窗口效率对比 | 柱状图对比各窗口处理效率与工作量 |
| 流程瓶颈分析 | 处方类型堆叠图 | 按处方类型堆叠展示各时段处方量 |
| 流程瓶颈分析 | 瓶颈桑基图 | 展示处方创建→缴费→配药→叫号→取药全流程流转与耗时 |
| 多维度对比 | 维度筛选器 | 按窗口、药师、科室、处方类型、时段进行筛选对比 |
| 明细详情 | 处方明细表 | 展示筛选后的原始处方记录，支持排序和分页 |
| 明细详情 | 人工备注面板 | 对异常数据点添加、编辑、查看人工备注 |

## 3. 核心流程

用户进入总览页面查看核心指标与异常预警→选择维度进行对比分析→发现异常数据点→点击下钻查看明细表→添加人工备注说明异常原因与改进措施

    D --> E["点击下钻查看明细"]
    E --> F["添加人工备注"]
    F --> G["形成运营改善记录"]

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：医疗蓝 (#165DFF）作为主色，搭配深灰 (#1D2129) 作为中性色，警示橙 (#FF7D00) 作为异常强调色
- 按钮风格：圆角矩形，主按钮使用主色填充，悬停有轻微阴影
- 字体：使用思源黑体 / PingFang SC 作为中文字体，数字使用等宽字体
- 布局风格：卡片式布局，顶部导航 + 侧边筛选 + 主内容区栅格布局
- 图标风格：使用 lucide-react 线性图标，保持简洁一致

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 运营复盘总览 | KPI指标卡 | 卡片带渐变背景、数字大字展示、趋势小图、异常标红 |
| 运营复盘总览 | 可视化图表区 | ECharts 图表、支持 tooltip 交互、点击下钻 |
| 多维度对比 | 筛选器面板 | 下拉选择器、日期范围、快捷选项卡切换 |
| 明细详情 | 数据表格 | 斑马纹、悬停高亮、可排序、分页 |
| 明细详情 | 备注面板 | 侧滑抽屉、时间线展示备注历史 |

### 4.3 响应式

采用桌面优先设计，适配 1440px 及以上宽屏显示器，支持平板设备适配

### 4.4 地图场景

Mapbox GL 用于展示医院药房窗口布局热力图（可选扩展）
