## 2. 技术说明

- **前端框架**：React 18 + TypeScript
- **样式方案**：TailwindCSS 3
- **构建工具**：Vite
- **状态管理**：Zustand（轻量、适合游戏状态）
- **动画库**：Framer Motion（UI过渡、物品动画）
- **音效**：Web Audio API + Howler.js（音频管理）
- **数据持久化**：localStorage（存档、行为追踪）
- **后端**：无（纯前端，所有数据本地存储）

## 3. 路由定义

| 路由 | 用途 |
|------|------|
| `/` | 主界面：标题动画、开始按钮、章节选择、设置 |
| `/tutorial` | 教程关卡：交互式操作引导 |
| `/game/:chapterId/:roomId` | 游戏场景：房间探索、物品交互 |
| `/game/:chapterId/:roomId/puzzle/:puzzleId` | 谜题界面：锁谜题、组合谜题 |
| `/notebook` | 笔记面板：线索列表、关联推理（浮层路由） |
| `/settlement/:chapterId` | 章节结算：统计数据、评分 |

## 4. 核心数据模型

### 4.1 游戏状态模型

```typescript
interface GameState {
  currentChapter: string;
  currentRoom: string;
  inventory: Item[];
  notebook: Clue[];
  clueLinks: ClueLink[];
  puzzleStates: Record<string, PuzzleState>;
  hintPoints: number;
  chaptersUnlocked: string[];
  tutorialCompleted: boolean;
  tutorialSkipped: boolean;
  totalPlayTime: number;
}

interface Item {
  id: string;
  name: string;
  description: string;
  imageKey: string;
  examinable: boolean;
  rotationAngle?: number;
  clues: string[];
}

interface Clue {
  id: string;
  text: string;
  sourceItem: string;
  sourceRoom: string;
  chapter: string;
  timestamp: number;
  linkedClues: string[];
}

interface ClueLink {
  from: string;
  to: string;
  label?: string;
}

interface PuzzleState {
  id: string;
  type: 'lock' | 'code' | 'combination';
  solved: boolean;
  attempts: number;
  hintsUsed: number;
  currentInput: string | number[];
  solution: string | number[];
  failCount: number;
}

interface ChapterConfig {
  id: string;
  title: string;
  intro: string;
  rooms: RoomConfig[];
  newRule: string;
  difficulty: number;
}

interface RoomConfig {
  id: string;
  name: string;
  backgroundKey: string;
  hotspots: Hotspot[];
  ambientSound: string;
  items: string[];
  puzzles: string[];
  narrativeEvents: NarrativeEvent[];
}

interface Hotspot {
  id: string;
  x: number;
  y: number;
  width: number;
  height: number;
  type: 'item' | 'examine' | 'door' | 'narrative';
  targetId: string;
  glowOnHover: boolean;
}

interface NarrativeEvent {
  id: string;
  trigger: string;
  text: string;
  soundEffect?: string;
  delay: number;
}
```

### 5.2 关卡配置分离

关卡配置以JSON文件独立存放，游戏引擎通过配置驱动渲染和逻辑：

```
src/
  config/
    chapters/
      chapter1.json    -- 第一章关卡配置
      chapter2.json    -- 第二章关卡配置
      chapter3.json    -- 第三章关卡配置
    items.json         -- 物品定义
    puzzles.json       -- 谜题定义
    tutorial.json      -- 教程步骤配置
    sounds.json        -- 音效映射配置
```

### 5.3 谜题难度曲线

| 章节 | 谜题类型 | 新规则 | 难度系数 |
|------|----------|--------|----------|
| 第一章 | 单线索密码锁 | 无（基础操作） | 1.0 |
| 第二章 | 双线索组合锁 | 需关联两条线索 | 1.3 |
| 第三章 | 多线索推理谜题 | 需排除干扰线索 | 1.6 |

### 5.4 提示系统分级

| 级别 | 内容 | 消耗 |
|------|------|------|
| L1 | 方向性提示（如"注意物品背面"） | 1点 |
| L2 | 具体提示（如"翻转到物品背面查看数字"） | 2点 |
| L3 | 直接答案 | 3点 |

每章起始提示点数：5点

## 7. 构建与调试流程

- **开发模式**：`npm run dev` — Vite热更新，调试面板自动开启
- **构建生产**：`npm run build` — 优化打包，调试面板移除
- **预览构建**：`npm run preview` — 本地预览生产构建
- **类型检查**：`npm run typecheck` — TypeScript编译检查
- **调试面板入口**：游戏中按 `~` 键或输入 "debug" 命令开启
- **调试面板功能**：关卡跳转、数值修改、行为日志查看、音效测试
