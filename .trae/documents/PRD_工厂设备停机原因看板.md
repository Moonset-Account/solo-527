## 1. 产品概述
工厂设备停机原因看板是一个面向生产主管和设备管理团队的数据分析平台，通过多维度可视化展示设备停机数据，帮助用户快速识别根因、优化维修资源配置、降低设备故障率。
- 解决问题：传统报表堆砌图表难以支撑决策，计划检修与突发停机混淆导致考核偏差
- 目标用户：生产主管、设备工程师、维修团队、工厂管理层
- 核心价值：通过Pareto分析、对比视图和关联分析，让数据驱动的设备管理决策可视化、可解释、可导出

## 2. 核心功能

### 2.1 用户角色
| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 生产主管 | 账号登录 | 查看所有看板、导出报告、配置筛选条件 |
| 设备工程师 | 账号登录 | 查看设备详情、下钻分析、查看备件关联 |
| 管理层 | 账号登录 | 查看汇总视图、导出报表、跨产线对比 |

### 2.2 功能模块
1. **总体概览页**：核心KPI卡片、筛选器面板、关键趋势指标
2. **停机Pareto分析页**：故障类型Pareto图、累积占比曲线、问题解释说明
3. **产线对比分析页**：多产线停机时长对比、OEE对比、故障分布热力图
4. **维修效率分析页**：维修时长分布、维修人绩效、MTTR/MTBF指标
5. **备件关联分析页**：故障类型与备件消耗关联、备件预警、成本分析

## 3. 核心流程
用户进入看板后，首先通过筛选器选择关心的维度（设备、产线、班次等），系统实时更新所有图表。用户可以在Pareto图上点击某类故障进行下钻，查看该故障在不同产线和设备上的分布。识别出关键问题后，用户可以导出报告，报告会自动包含当前的筛选条件、数据口径和图表数据。

```mermaid
flowchart LR
    A["进入看板"] --> B["选择筛选条件<br/>(设备/产线/班次/时间)"]
    B --> C["视图自动刷新<br/>(计划/突发分离统计)"]
    C --> D["查看Pareto分析<br/>识别Top故障"]
    D --> E["点击下钻<br/>查看产线/设备分布"]
    E --> F["查看备件关联<br/>分析维修成本"]
    F --> G["导出报告<br/>(含口径说明)"]
    G --> H["数据驱动决策"]
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：工业蓝 (#1E3A5F) 作为主色，代表专业和可靠性
- **强调色**：警示橙 (#FF6B35) 用于突出突发停机，成功绿 (#2ECC71) 用于计划检修
- **中性色**：深灰 (#2C3E50) 文字，浅灰 (#ECF0F1) 背景，卡片纯白 (#FFFFFF)
- **按钮风格**：圆角6px，轻微阴影，hover状态有透明度变化
- **字体**：标题使用 "Roboto Slab" 衬线字体体现专业感，正文使用 "Noto Sans SC" 无衬线保证可读性
- **布局风格**：卡片式布局，清晰的网格系统，充足的留白，图表与解释文字并排展示
- **图标风格**：线性图标，统一2px描边，工业设备风格

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|-----------|-------------|-------------|
| 总体概览 | KPI卡片 | 大数字指标+趋势箭头+小型迷你图，卡片带微妙阴影 |
| 总体概览 | 筛选器面板 | 标签式多选项框，水平排列，选中状态高亮 |
| 总体概览 | 趋势图 | 面积图，计划检修绿色填充，突发停机橙色填充 |
| 停机Pareto | Pareto图 | 左轴柱状图(故障时长)，右轴折线(累积占比)，80%处参考线 |
| 停机Pareto | 解释面板 | 卡片内文字说明，每类故障配建议动作图标 |
| 产线对比 | 对比图 | 分组柱状图，不同颜色区分产线，数据标签显示 |
| 维修效率 | 分布图 | 箱线图显示离散程度，异常值红色标注 |
| 备件关联 | 关联矩阵 | 热力图颜色深浅表示关联强度，hover显示详情 |

### 4.3 响应式
- 桌面端优先设计，最小支持1280px宽度
- 平板端自适应调整网格列数，筛选器改为垂直堆叠
- 移动端KPI卡片堆叠展示，图表支持横向滚动

### 4.4 动效设计
- 页面加载：卡片依次淡入，带轻微上移动画
- 筛选变更：图表数据平滑过渡动画(500ms)
- Hover效果：卡片轻微上浮，阴影加深
- 加载状态：骨架屏+脉冲动画
- 数据点交互：点击后高亮并平滑下钻
