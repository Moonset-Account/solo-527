## 1. 产品概述

汽车保养预约收银系统是面向汽修店的一体化 Web 应用，提供从检测项目浏览、在线预约、技师工位调度、配件管理、收银结算到返修追踪的全流程服务，帮助汽修店提升运营效率和服务质量。

- 核心目标：实现汽车保养服务的数字化管理，优化预约调度流程，提升客户复购率
- 目标用户：汽修店老板、技师、前台接待人员、车主用户
- 市场价值：通过数字化管理降低运营成本，提升客户满意度和复购率

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 车主用户 | 手机号/邮箱注册 | 浏览检测项目、提交预约、查看会员信息、查看服务记录 |
| 管理员 | 后台创建账号 | 全部管理权限：技师工位、检测模板、配件、收银单、返修、报表 |
| 技师 | 后台创建账号 | 查看分配任务、记录检测结果、上传附件、填写备注 |

### 2.2 功能模块

1. **用户端首页**：检测项目展示、快捷预约入口、会员套餐推荐
2. **检测项目列表**：项目分类、价格展示、详情查看
3. **预约页面**：选择项目、选择时间、车辆信息填写
4. **会员中心**：会员信息、套餐余额、服务历史、复购记录
5. **管理端仪表盘**：今日预约、营收概览、工位状态
6. **技师工位管理**：技师档案、工位配置、排班调度
7. **检测模板维护**：模板列表、项目配置、价格管理
8. **配件管理**：配件档案、库存管理、报价设置
9. **收银单管理**：生成账单、收款记录、发票管理
10. **返修追踪**：返修工单、处理记录、质量分析
11. **数据报表**：会员复购报表、服务质量分析、营收统计

## 3. 核心流程

### 3.1 预约服务流程
用户浏览检测项目 → 选择项目和时间 → 填写车辆信息 → 提交预约 → 系统分配技师工位 → 用户到店 → 技师检测 → 记录结果与配件 → 生成收银单 → 完成支付 → 服务评价 → 更新会员复购数据

```mermaid
flowchart LR
    A["用户浏览项目"] --> B["选择项目和时间"]
    B --> C["填写车辆信息"]
    C --> D["提交预约"]
    D --> E["系统分配技师工位"]
    E --> F["用户到店检测"]
    F --> G["记录检测结果"]
    G --> H["登记配件使用"]
    H --> I["生成收银单"]
    I --> J["完成支付"]
    J --> K["服务评价"]
    K --> L["更新会员复购数据"]
```

### 3.2 返修处理流程
用户反馈问题 → 创建返修工单 → 分配负责人 → 检测异常原因 → 处理修复 → 质量验收 → 记录流转 → 更新复购报表

```mermaid
flowchart LR
    A["用户反馈问题"] --> B["创建返修工单"]
    B --> C["分配负责人"]
    C --> D["检测异常原因"]
    D --> E["处理修复"]
    E --> F["质量验收"]
    F --> G["记录流转历史"]
    G --> H["更新服务质量统计"]
    H --> I["反映到会员复购报表"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **设计方向**：工业风 + 专业感，体现汽修行业的专业可靠形象
- **主色调**：深蓝色系 (#0F172A / #1E3A5F) 代表专业与信任
- **辅助色**：橙黄色 (#F59E0B) 用于强调操作和警示
- **成功色**：翠绿色 (#10B981) 用于状态提示
- **字体**：标题使用 Space Grotesk，正文使用 Inter，数字使用等宽字体
- **布局风格**：卡片式布局，清晰的信息层级，数据表格密集但有序
- **图标风格**：线性图标（Lucide），简洁专业

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 用户端首页 | 英雄区域 | 全屏大图背景、渐变遮罩、大标题、主按钮悬浮动效 |
| 用户端首页 | 项目卡片 | 卡片悬浮效果、价格高亮、渐入动画 |
| 管理仪表盘 | 数据卡片 | 深色背景、大数字、趋势箭头、图标装饰 |
| 管理仪表盘 | 工位状态 | 网格布局、状态色块、实时更新动效 |
| 数据表格 | 列表组件 | 斑马纹、行悬浮高亮、状态标签、操作按钮组 |
| 详情页面 | 侧边布局 | 左侧信息列表、右侧操作区、时间轴历史记录 |

### 4.3 响应式设计

- 采用桌面优先设计，适配 1440px 及以上宽度
- 平板端：侧边栏收起为图标模式，表格支持横向滚动
- 移动端：底部导航栏，卡片单列布局，表单简化

### 4.4 交互细节

- 按钮悬浮：背景色渐变 + 轻微上浮动效
- 数据加载：骨架屏 + 淡入动画
- 状态变化：数字滚动动画、状态标签颜色过渡
- 表单提交：按钮加载状态 + 成功提示
- 页面切换：淡入淡出过渡
