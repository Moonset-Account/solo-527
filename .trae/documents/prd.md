## 1. 产品概述

园区电表能耗看板系统，面向园区能源管理员、管理层和一线运维人员，提供电表能耗实时监控、设备告警管理、表计分区管理、补贴记录追踪及数据查询导出等能力。核心解决能耗数据不透明、告警响应难以追溯、同步失败信息不友好等问题。

- 目标用户：园区能源管理员（日常操作）、管理层（决策复盘）、一线运维人员（现场处置）
- 核心价值：实现能耗数据可视化、告警全流程可追溯、同步失败可诊断重试，提升园区能源管理效率和响应速度

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 能源管理员 | 管理员分配账号 | 查看能耗曲线、管理表计与分区、查询下载数据、处理告警 |
| 管理层 | 管理员分配账号 | 查看能耗看板、告警复盘、补贴记录审计、关联单据查看 |
| 一线运维 | 管理员分配账号 | 查看同步状态、重试同步、查看告警详情、处置反馈 |

### 2.2 功能模块

1. **能耗看板**：实时能耗总览、分区能耗对比、尖峰时段标记、能耗曲线趋势
2. **表计管理**：电表接入登记、分区绑定、表计状态监控、同步记录查看
3. **分区管理**：园区分区创建编辑、分区关联表计、分区能耗汇总
4. **告警管理**：设备告警列表、告警响应追踪、尖峰异常原因记录、责任人与响应时长、月度告警复盘
5. **补贴记录**：补贴登记、关联来源单据、补充说明、补贴统计
6. **数据查询下载**：能耗数据多条件查询、数据导出Excel、历史数据对比
7. **同步管理**：同步任务列表、失败原因展示、重试操作、重试结果追踪

## 3. 核心流程

**能耗监控流程**：管理员登录 → 查看能耗看板 → 发现异常/尖峰 → 下钻分区 → 定位表计 → 处理或升级告警

**告警响应流程**：系统检测异常 → 生成告警 → 推送责任人 → 责任人确认 → 记录响应时长 → 填写处理结果与补充说明 → 关联来源单据 → 告警关闭

**月度复盘流程**：管理层进入复盘页面 → 查看本月告警汇总 → 分析尖峰异常原因TOP → 审查响应时长分布 → 查看责任人处置情况 → 导出复盘报告

**同步失败处理流程**：同步任务失败 → 系统展示失败原因（非原始报错）→ 一线人员查看诊断信息 → 点击重试 → 查看重试结果 → 仍失败则升级

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深青色（#0F4C5C）作为品牌色，搭配暖橙色（#E36414）作为告警/强调色
- 辅助色：浅灰底色（#F7F8FA）、白色卡片、深灰文字（#2D3436）
- 按钮风格：圆角（border-radius: 8px），主按钮实色填充，次按钮描边
- 字体：思源黑体/Noto Sans SC，标题 20px/16px，正文 14px，辅助文字 12px
- 布局风格：左侧固定导航栏 + 顶部工具栏 + 内容区卡片式布局
- 图标风格：线性图标（Element Plus图标库），统一 16px/20px 尺寸
- 告警等级色彩：紧急红色、警告橙色、提示蓝色、信息灰色

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 能耗看板 | 能耗总览卡片 | 3-4个统计卡片横向排列，数字加粗放大，同比箭头图标，浅色背景渐变 |
| 能耗看板 | 能耗曲线 | ECharts折线图，尖峰区域橙色填充，支持拖拽缩放，工具栏切换日/周/月 |
| 能耗看板 | 分区对比 | ECharts柱状图，悬停显示详情，点击跳转分区详情 |
| 表计管理 | 表计列表 | Element Plus表格，状态标签彩色，操作列按钮组，顶部搜索筛选栏 |
| 告警管理 | 告警列表 | 紧急告警行红色背景，分页器，筛选器（类型/等级/状态/时间） |
| 告警管理 | 月度复盘 | 统计卡片 + 饼图/柱图 + 响应时长分布图 + TOP表格 |
| 补贴记录 | 补贴列表 | 表格展示，单据号可点击跳转，补充说明列显示省略+tooltip |
| 同步管理 | 失败详情 | 原因分类标签，友好描述文本框，重试按钮带loading，重试结果时间线 |

### 4.3 响应式设计

- 桌面优先设计，支持 1280px+ 分辨率
- 中等屏幕（1024-1280px）侧边栏可折叠
- 小屏幕（<1024px）侧边栏收起为抽屉模式，表格横向滚动

## 5. 补充说明

- 所有涉及单据关联的模块（告警、补贴、表计分区）必须提供来源单据编号和链接入口
- 同步失败页面禁止展示原始系统报错（如Java堆栈），必须转换为友好描述（如"网络连接超时，请检查采集器网络"）
- 月度复盘数据需支持导出为Excel/PDF
- 能耗数据下载支持CSV和Excel格式
- 告警响应时长从告警生成到责任人确认的时间差自动计算
