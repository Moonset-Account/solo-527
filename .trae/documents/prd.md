## 1. 产品概述

城市路口信号灯模拟是一款策略模拟游戏，玩家通过调整红绿灯周期与公交优先规则来疏导早晚高峰车流。核心挑战在于在有限时间内找到最优信号配时方案，让交通尽可能顺畅。目标用户为喜欢策略规划与城市管理的休闲玩家，单局体验约10分钟。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 |
|------|------|
| 交通指挥官 | 玩家身份，负责调整信号灯与公交优先策略 |

### 2.2 功能模块

1. **开始菜单**：游戏标题、开始游戏、关卡选择、沙盒模式、设置
2. **教程关卡**：逐步引导玩家学习信号灯调整、公交优先、拥堵评分
3. **关卡1-5**：递进难度的策略挑战，从单路口到多路口路网
4. **沙盒模式**：自由调整参数，无胜负限制
5. **结算界面**：展示拥堵评分、通行量、对比上次调整效果
6. **回放系统**：每次调整后可回放效果并比较指标

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝黑（#0a0e1a）城市夜景背景，霓虹绿（#00ff88）与琥珀橙（#ff8800）作为信号灯色彩
- **辅色调**：道路灰（#2a2d3a）、车辆白/红/蓝、公交黄（#ffd700）
- **按钮风格**：圆角矩形，霓虹发光边框，hover时发光增强
- **字体**：标题使用 Orbitron（科技感），正文使用 Noto Sans SC
- **布局风格**：左侧3D道路网视图，右侧控制面板，底部评分条
- **图标风格**：线性图标，霓虹发光效果
- **动画**：信号灯切换脉冲、车流流动、拥堵热力图渐变、调整回放过渡

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 开始菜单 | 背景 | 深蓝黑渐变，动态城市天际线剪影，流动车灯粒子 |
| 开始菜单 | 标题 | Orbitron字体，霓虹绿发光，脉冲动画 |
| 开始菜单 | 按钮 | 圆角矩形，琥珀橙边框发光，hover放大+亮度增加 |
| 关卡选择 | 关卡卡片 | 深色卡片，左上角编号，星级评价，锁定图标 |
| 游戏主界面 | 3D视图 | 俯视45度道路网，信号灯3D模型，车辆动画 |
| 游戏主界面 | 控制面板 | 右侧半透明面板，滑块、开关、按钮 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度1280px
- 3D视图自适应缩放
- 控制面板可折叠

### 4.4 3D场景指引

- **环境**：城市夜景，深蓝黑天空，远处建筑剪影
- **光照**：环境光低亮度 + 路灯点光源 + 信号灯自发光
- **摄像机**：正交俯视45度角，可平移缩放
- **焦点**：交叉路口信号灯，车流动线
- **交互**：点击路口选中，拖拽平移，滚轮缩放
- **动画**：车辆行驶、信号灯切换、拥堵变色
- **后处理**：Bloom效果用于霓虹灯光，轻微景深
- **资产来源**：程序化生成道路、建筑、车辆几何体
- **性能预算**：60FPS，最大200辆车，4-9个路口

## 5. 关卡设计

### 关卡1：新手路口
- 单路口，2条路交叉
- 低车流量，无公交
- 教学信号灯周期调整
- 目标：让拥堵评分低于30

### 关卡2：早高峰
- 单路口，2条路交叉
- 高车流量，主路方向车流大
- 引入方向不均衡概念
- 目标：主路拥堵评分低于20

### 关卡3：公交优先
- 双路口，含公交路线
- 中等车流量，2条公交线路
- 教学公交优先策略
- 目标：公交通行时间减少30%

### 关卡4：复杂路网
- 4路口网格路网
- 高车流量，多方向
- 需要协调多个路口信号灯
- 目标：整体拥堵评分低于25

### 关卡5：终极挑战
- 9路口网格路网
- 极高车流量，多条公交线
- 早晚高峰切换
- 目标：高峰期拥堵评分低于35

## 6. 数值系统

### 拥堵评分
- 0-100分，0为完全畅通，100为严重拥堵
- 基于每辆车等待时间加权平均
- 公交车等待时间权重×3

### 信号灯周期
- 每个方向绿灯时长：10-90秒
- 黄灯固定3秒
- 最小周期20秒，最大周期180秒

### 公交优先
- 公交检测距离：50米
- 优先策略：提前切换、延长绿灯
- 优先冷却时间：30秒

### 胜负判定
- 3星：拥堵评分 ≤ 目标值×0.6
- 2星：拥堵评分 ≤ 目标值×0.8
- 1星：拥堵评分 ≤ 目标值
- 失败：拥堵评分 > 目标值 或 时间用尽未达标
