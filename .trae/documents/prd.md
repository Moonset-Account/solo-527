## 1. 产品概述

工厂设备停机原因看板——为生产主管打造的一站式停机分析平台，整合设备运行、报警、维修工单、班组、产量和备件消耗六大数据源，通过可视化图表与联动筛选揭示停机根因，支持计划检修与突发停机分离统计，每周自动生成可下载的周报（含同比环比、异常点、筛选口径），导出格式支持 PDF 和图片。

- 目标用户：工厂生产主管、设备工程师、维修班组长
- 核心价值：从"只看总数"升级到"解释变化原因"，消除计划检修与突发停机混淆带来的考核误导

## 2. 核心功能

### 2.1 用户角色

| 角色 | 访问方式 | 核心权限 |
|------|----------|----------|
| 生产主管 | 账号登录 | 查看看板全部图表、筛选联动、生成/下载周报、导出 PDF/图片 |
| 设备工程师 | 账号登录 | 查看看板、筛选联动、查看数据质量报告 |
| 维修班组长 | 账号登录 | 查看本班组相关停机数据、筛选本班组维修记录 |

### 2.2 功能模块

1. **看板主页面**：全局筛选栏、停机 Pareto 图、产线对比图、维修时长分析、备件关联分析、KPI 概览卡
2. **周报生成页面**：自动汇总本周关键变化、同比环比、异常点、筛选口径，支持 PDF/图片导出
3. **数据治理说明面板**：原始数据入库流程、聚合规则、脏数据处理策略说明

## 3. 核心流程

### 3.1 看板交互流程

用户进入看板 → 默认加载本周全厂数据 → 通过筛选栏选择维度（设备/产线/班次/故障类型/维修人）→ 所有图表联动响应 → 切换"仅计划检修"/"仅突发停机"模式 → 点击 Pareto 图某故障类型下钻 → 产线对比与维修时长同步聚焦 → 备件关联自动高亮相关备件

### 3.2 周报生成流程

系统每周一自动触发周报生成 → 聚合上周数据 → 计算同比环比 → 检测异常点 → 记录当前筛选口径 → 渲染报告模板 → 用户可在周报页面预览 → 一键导出 PDF 或图片

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝 (#1B2A4A) + 警示橙 (#FF6B35) + 状态绿 (#2ECC71)，工业感配色
- 辅助色：计划检修蓝 (#3498DB)、突发停机红 (#E74C3C)、中性灰 (#95A5A6)
- 按钮风格：圆角微弧（4px），主要操作用实色填充，次要操作用线框
- 字体：标题使用 DIN Alternate（工业仪表风格），正文使用 Noto Sans SC
- 布局：左侧固定筛选面板 + 右侧自适应图表网格，顶部 KPI 卡片条
- 图标风格：线性图标，2px 描边，工业仪表盘风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 看板主页面 | 全局筛选栏 | 侧边栏，下拉多选+日期范围+计划/突发切换开关，深色背景 |
| 看板主页面 | KPI 概览卡 | 顶部横排5张卡片，数字大号+趋势小箭头+迷你趋势图 |
| 看板主页面 | 停机 Pareto 图 | 左侧柱状图（双色区分计划/突发）+ 右侧累计百分比折线 |
| 看板主页面 | 产线对比图 | 水平堆叠柱状图，hover 显示详情，点击下钻 |
| 看板主页面 | 维修时长分析 | 直方图+箱线图组合，分组标签，异常值红点标记 |
| 看板主页面 | 备件关联分析 | 气泡散点图（X:停机时长 Y:备件消耗 大小:频次），右侧排名列表 |
| 周报生成页面 | 周报概览 | A4 纸张预览布局，关键变化用色块高亮，异常点用警示图标 |
| 周报生成页面 | 导出控制 | 底部固定工具栏，PDF/图片切换按钮，筛选条件水印预览 |
| 数据治理说明面板 | 流程与规则 | 手风琴折叠面板，流程图+规则表+策略卡片 |

### 4.3 响应式策略

- 桌面优先（1920px+），图表网格 2×2 布局
- 平板（1024px）筛选栏折叠为顶部抽屉，图表单列堆叠
- 移动端（768px-）仅展示 KPI 卡片和 Pareto 图，其余图表按需展开

### 4.4 无障碍

- 所有图表提供数据表格替代视图
- 颜色区分辅以形状/纹理区分（计划检修斜线填充、突发停机实色填充）
- 键盘可操作筛选与图表交互
