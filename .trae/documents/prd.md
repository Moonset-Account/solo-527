## 1. 产品概述
跨境电商退货分析看板，帮助运营团队精准定位退货原因，降低退货率和退款损失。面向跨境电商运营、仓配和质控团队，通过可视化手段将退货率趋势、物流延误关联、SKU 排名与质检下钻整合在同一界面，实现从宏观到微观的全链路退货归因。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 运营人员 | SSO 登录 | 查看看板全部图表、导出报表 |
| 仓配管理员 | SSO 登录 | 查看看板、下钻质检结论、标记仓库破损 |
| 质控主管 | SSO 登录 | 全部查看权限 + 配置退货原因映射 + 审核低样本阈值 |

### 2.2 功能模块
1. **总览看板**：退货率趋势图、核心 KPI 卡片、仓库口径切换（海外仓/国内仓）
2. **SKU 排名与下钻**：高退货率 SKU 排行榜（含低样本提示）、SKU 详情下钻
3. **物流延误关联**：物流节点延误率与退货率散点图、延误退货归因
4. **质检分析**：质检结论分布、仓库破损 vs 消费者原因分层、退款金额按币种换算

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 总览看板 | KPI 卡片组 | 展示总退货率、总退款金额（统一币种）、退货订单数、平均处理时长 |
| 总览看板 | 退货率趋势 | 按日/周/月粒度的退货率折线图，支持海外仓与国内仓口径切换 |
| 总览看板 | 仓库口径切换器 | 海外仓/国内仓 Tab 切换，切换后所有图表联动刷新 |
| SKU 排名 | 高退货率 SKU 排行榜 | Top N SKU 按退货率降序排列，样本量不足的 SKU 显示「样本不足」提示且不参与排名 |
| SKU 排名 | SKU 详情下钻面板 | 点击 SKU 展开退货原因分布、物流延误关联、质检结论明细 |
| 物流关联 | 物流节点延误散点图 | X 轴为物流延误率，Y 轴为退货率，气泡大小为订单量 |
| 物流关联 | 延误节点退货归因表 | 按物流节点维度展示延误退货数与占比 |
| 质检分析 | 质检结论分布图 | 饼图/环形图展示仓库破损、消费者原因、其他质检结论的占比 |
| 质检分析 | 仓库破损分层表 | 仓库破损退货与消费者原因退货分别统计，互不混淆 |
| 质检分析 | 退款金额报表 | 按币种换算为统一口径（USD），展示各维度退款汇总 |

## 3. 核心流程

用户打开看板 → 选择仓库口径（海外仓/国内仓）→ 浏览退货率趋势定位异常时段 → 点击异常时段查看 SKU 排名 → 下钻 SKU 查看退货原因与物流关联 → 进入质检分析区分仓库破损与消费者原因 → 导出退款金额报表。

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深蓝灰（#1B2A4A）搭配警示橙（#FF6B35）和状态绿（#2ECB71）
- 辅助色：浅灰背景（#F0F2F5）、卡片白（#FFFFFF）、边框灰（#D9DDE4）
- 按钮：圆角 6px，主操作用实色填充，次操作用描边
- 字体：标题使用 DM Sans（粗体 700），正文使用 Noto Sans SC（常规 400/500）
- 布局：左侧固定导航栏 + 顶部仓库口径切换，卡片式模块布局
- 图标：线性图标风格（Phosphor Icons 风格），统一 20px 尺寸

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 总览看板 | KPI 卡片组 | 四张统计卡片横排，深色底+大号数字+趋势小箭头 |
| 总览看板 | 退货率趋势 | 折线图，双线（海外仓/国内仓），时间轴可拖拽 |
| 总览看板 | 仓库口径切换器 | 顶部 Tab 组件，左侧标签+高亮下划线 |
| SKU 排名 | 排行榜表格 | 表格行+进度条+低样本黄色提示标签 |
| SKU 排名 | 下钻面板 | 右侧抽屉式面板，内含环形图+列表 |
| 物流关联 | 散点图 | 气泡散点图，气泡悬停显示详情 tooltip |
| 质检分析 | 饼图/环形图 | 双环形图：仓库破损内环+消费者原因外环 |
| 质检分析 | 退款金额表 | 表格+币种标签徽章+换算后金额列 |

### 4.3 响应式
- 桌面优先设计，最小适配 1280px 宽度
- 平板端（768-1280px）卡片由四列变两列，图表保持全宽
- 移动端（<768px）导航栏折叠为底部 Tab，卡片单列堆叠
