## 1. 产品概述
园区食堂菜品满意度分析平台，将销量、评价、退餐和成本数据整合在同一页面，帮助后勤人员快速识别菜品质量问题、追踪退餐原因、监控成本毛利，并支持供应商更换和食材批次召回等特殊事件的标记与追溯。
- 解决问题：食堂运营数据分散、低分菜品误判、退餐原因难追溯、供应商更换评价混淆、食材召回影响范围不明
- 目标用户：园区后勤管理人员、食堂运营负责人

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 后勤管理员 | 系统分配账号 | 查看所有数据、筛选分析、下载报表、标记供应商更换/食材召回 |
| 食堂运营人员 | 系统分配账号 | 查看本窗口数据、筛选分析、下载报表 |

### 2.2 功能模块
1. **满意度分析总览页**：满意度矩阵、退餐原因分布、成本毛利图、样本量阈值指示、异常菜品明细、报表下载
2. **筛选面板**：按窗口、菜系、时段、成本区间、供应批次筛选

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 满意度分析总览 | 筛选面板 | 支持按窗口、菜系、时段、成本区间、供应批次多维筛选，筛选结果联动所有图表 |
| 满意度分析总览 | 满意度矩阵 | 横轴销量、纵轴评分的散点矩阵，气泡大小代表样本量，供应商更换日用特殊标记区分，食材召回菜品用特殊符号标识 |
| 满意度分析总览 | 退餐原因分布 | 饼图/环形图展示退餐原因分类占比，点击可下钻到当天窗口详情 |
| 满意度分析总览 | 成本毛利图 | 双轴图展示菜品成本与毛利率，支持成本区间筛选联动 |
| 满意度分析总览 | 样本量阈值指示 | 样本量不足的菜品用警告色标识，不进入低分排行榜 |
| 满意度分析总览 | 异常菜品明细 | 表格列出评分异常、退餐率异常、成本异常的菜品，支持供应商更换和食材召回标记 |
| 满意度分析总览 | 报表下载 | 导出当前筛选条件下的分析报表（CSV/Excel） |

## 3. 核心流程

后勤人员进入总览页 → 使用筛选面板选择关注维度 → 查看满意度矩阵定位问题菜品 → 退餐原因分布追查根因 → 成本毛利图评估经济性 → 异常菜品明细获取详情 → 下载报表归档

供应商更换流程：后台标记某窗口某天更换供应商 → 该日期口味评价单独标记 → 不与历史评价混算 → 图表上用特殊符号区分

食材批次召回流程：标记受影响批次 → 关联受影响菜品 → 图表评价趋势上用特殊符号区分 → 异常菜品明细中高亮

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深青色（#0F766E）+ 琥珀色强调（#D97706）
- 辅助色：石板灰系（zinc）做中性色，警告用红色（#DC2626），召回用紫色（#7C3AED）
- 按钮风格：圆角矩形，带微妙阴影
- 字体：思源黑体 / Noto Sans SC，标题 20px，正文 14px，标注 12px
- 布局风格：顶部筛选栏 + 网格卡片式图表区域
- 图标风格：线性图标（lucide-react）

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 满意度分析总览 | 筛选面板 | 顶部固定栏，下拉选择器（窗口、菜系、时段、供应批次），滑块（成本区间），应用/重置按钮 |
| 满意度分析总览 | 满意度矩阵 | ECharts 散点图，四象限分区，气泡大小编码样本量，供应商更换日用菱形标记，召回菜品用三角形标记，hover 显示详情 |
| 满意度分析总览 | 退餐原因分布 | ECharts 环形图 + 右侧原因列表，点击扇区下钻到窗口明细表 |
| 满意度分析总览 | 成本毛利图 | ECharts 双轴柱状图，左轴成本，右轴毛利率，颜色区分成本区间 |
| 满意度分析总览 | 样本量阈值 | 阈值线标注在满意度矩阵和明细表中，低于阈值菜品用虚线边框 + 灰色标签"样本不足" |
| 满意度分析总览 | 异常菜品明细 | 表格，列含菜品名、窗口、评分、退餐率、成本、毛利率、供应商更换标记、召回标记、操作按钮 |
| 满意度分析总览 | 报表下载 | 卡片右上角下载按钮，支持 CSV/Excel 格式选择 |

### 4.3 响应式设计
- 桌面优先设计，大屏（≥1440px）展示完整矩阵 + 三图并排
- 平板（768-1439px）矩阵占满宽 + 图表上下排列
- 手机（<768px）所有内容纵向堆叠，图表可横向滚动

### 4.4 特殊标记规范
- 供应商更换当天：菱形标记（◆），颜色 #D97706，tooltip 注明"供应商更换日"
- 食材批次召回：三角形标记（▲），颜色 #7C3AED，tooltip 注明"食材批次召回"
- 样本不足：灰色虚线边框，标签"样本不足"，不参与低分排行
