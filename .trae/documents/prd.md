## 1. 产品概述

水产养殖水质监控看板——面向养殖技术员的实时水质数据监控与决策辅助平台。通过接入溶氧、温度、pH、投喂量、增氧机状态等多维传感器数据，结合鱼塘批次管理，为技术员提供实时曲线、阈值告警、投喂影响分析、批次对比等核心视图，确保异常可溯源、告警可复盘、操作可追踪。

- 核心目标：降低因水质异常导致的养殖损失，提升技术员响应效率与决策质量
- 目标用户：水产养殖场技术员、场长、质量管理员

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 技术员 | 管理员分配账号 | 查看实时数据、处理告警、导出报表、添加备注 |
| 场长 | 管理员分配账号 | 技术员全部权限 + 配置阈值、管理批次、查看复盘报表 |
| 管理员 | 系统内置 | 全部权限 + 用户管理、设备管理、系统配置 |

### 2.2 功能模块

1. **实时监控看板**：多指标实时曲线、阈值告警横幅、设备在线状态、投喂注释叠加
2. **告警中心**：阈值越限告警、设备离线告警、告警确认与人工判断记录
3. **投喂影响分析**：投喂策略变更注释、投喂量与水质指标关联曲线
4. **批次对比**：跨鱼塘/跨批次水质指标对比、筛选器上下文保持
5. **异常下钻**：异常点回溯原始采样记录、查看处理备注与人工判断
6. **报表导出**：日报/周报/自定义时段报表、包含告警与处理记录

## 3. 核心流程

### 3.1 实时监控与告警流程

技术员登录系统 → 查看看板实时曲线 → 收到阈值越限告警 → 查看告警详情与曲线定位 → 确认告警并填写人工判断 → 系统记录判断结果 → 周复盘时查阅汇总

### 3.2 异常下钻流程

技术员在曲线上发现异常点 → 点击异常点 → 查看原始采样记录（时间戳、传感器ID、原始值） → 查看关联告警与处理备注 → 必要时补充处理备注

### 3.3 投喂策略变更流程

场长修改投喂策略 → 系统在曲线上自动添加竖线注释 → 技术员 hover 查看变更内容 → 观察投喂后水质变化趋势

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝绿 (#0A2E36) 作为背景基底，象征水体深度与专业性
- 辅助色：青蓝 (#00B4D8) 表示正常状态，琥珀色 (#F59E0B) 表示警告，珊瑚红 (#EF4444) 表示危险
- 按钮风格：圆角微凸（border-radius: 8px），带有轻微阴影与 hover 渐变效果
- 字体：思源黑体 Noto Sans SC 作为主字体，数字使用 JetBrains Mono 等宽字体确保数据对齐
- 布局风格：左侧导航栏 + 顶部筛选器条 + 主内容区卡片式布局，曲线区域占主体
- 图标风格：线性图标 (Phosphor Icons)，2px 线宽，与数据面板风格统一

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 实时监控看板 | 多指标实时曲线 | 深色背景折线图，网格线半透明，曲线发光效果，离线段虚线+灰色填充 |
| 实时监控看板 | 阈值告警横幅 | 顶部琥珀色/红色横幅，左滑滚动，含指标名+当前值+阈值 |
| 实时监控看板 | 设备状态面板 | 右侧卡片，绿色圆点=在线，红色圆点=离线，显示最后通信时间 |
| 实时监控看板 | 投喂注释层 | 曲线竖线+顶部标签，hover 弹出卡片显示策略详情 |
| 告警中心 | 告警列表 | 左侧时间轴，右侧告警卡片，未处理=琥珀边框，已处理=灰色 |
| 告警中心 | 告警确认弹窗 | 模态框，必选判断类型+可选文字备注+关联异常点 |
| 投喂影响分析 | 关联图 | 双Y轴图，柱状图(投喂量)+折线(水质)，注释标签 |
| 批次对比 | 对比视图 | 多条曲线叠加，图例可切换，顶部筛选栏保持上下文 |
| 异常下钻 | 下钻面板 | 右侧滑出面板，显示原始采样值表格+告警处理时间线 |
| 报表导出 | 导出面板 | 日期选择器+多选鱼塘+指标选择，预览缩略图+导出按钮 |

### 4.3 响应式

- 桌面优先设计，最低支持 1280px 宽度
- 平板端 (768-1280px)：侧边栏折叠为图标模式，曲线图自适应缩放
- 移动端暂不支持（养殖现场使用平板或桌面设备为主）

### 4.4 关键交互约束

1. **传感器离线处理**：离线时段曲线必须断开显示（虚线或空白），禁止用上次读数插值填充；断线区域标注"设备离线"
2. **投喂注释**：策略变更时自动在曲线上添加可交互注释标记
3. **告警人工判断**：确认告警时必须选择判断类型，记录判断时间与人员
4. **异常点下钻**：点击任何数据点可追溯至原始采样记录，已处理异常可查看处理备注链
5. **筛选器上下文**：切换鱼塘/批次/指标时，时间范围、图表类型等上下文保持一致
