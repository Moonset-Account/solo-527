## 1. 产品概述

电子电路沙盒是一款面向初学者的教育型电路仿真工具，通过拖拽电阻、电容、开关、灯泡等元件，连线观察电路状态变化，逐步掌握基础电路概念。产品强调教学近似仿真而非专业工程精度，界面需明确标注"仅用于教学演示"。

- 目标用户：电路初学者、中学物理学生、自学电子爱好者
- 核心价值：通过交互式关卡渐进学习电路原理，记录学习行为数据优化教学路径

## 2. 核心功能

### 2.1 功能模块

1. **工作台页面**：元件面板 + 画布 + 属性面板，拖拽放置元件、连线、仿真运行
2. **教程系统**：交互式引导教程，逐步带出核心动作
3. **关卡挑战**：8个渐进难度关卡，从基础回路到自由探索
4. **暂停/设置页面**：暂停仿真、修改设置、重做关卡
5. **结算页面**：关卡完成统计、失败/重试数据展示

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 工作台 | 元件面板 | 拖拽电阻/电容/开关/灯泡/电池到画布 |
| 工作台 | 画布区域 | Canvas绘制电路，支持缩放平移，网格吸附 |
| 工作台 | 属性面板 | 选中元件后编辑参数值（阻值、电容值等） |
| 工作台 | 状态栏 | 仿真状态、FPS、元件数、关卡、教学免责声明 |
| 工作台 | 顶部工具栏 | 教程/提示/重置/保存/加载/分享/暂停/设置 |
| 教程弹层 | 步骤引导 | 高亮目标区域，步骤文字提示，等待玩家操作 |
| 暂停弹层 | 暂停控制 | 重做本关 / 继续仿真 |
| 设置弹层 | 参数配置 | 网格/吸附/仿真速度/音量/语言/快捷键/性能统计/自动保存/主题 |
| 结算弹层 | 通关统计 | 完成时间、重试次数、提示使用次数、评分 |

## 3. 核心流程

用户进入应用 → 首关教程引导（拖电池→拖灯泡→连线→灯泡亮）→ 关卡目标达成 → 结算页面 → 下一关 → 逐步解锁新元件和新规则 → 自由探索模式。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝背景（#1a1a2e）+ 霓虹红强调色（#e94560）
- 辅助色：电路线绿色（#00ff88）、警告黄（#f9ed69）
- 按钮风格：圆角矩形，hover时发光边框
- 字体：系统字体栈，monospace用于数值显示
- 布局：左侧元件面板 + 中央画布 + 右侧属性面板 + 顶部工具栏 + 底部状态栏
- 图标风格：简洁线条风格，电路符号化

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 工作台 | 元件面板 | 56x56卡片，内含Canvas缩略图+标签，拖拽光标 |
| 工作台 | 画布区域 | 深色背景+点阵网格，元件/导线渲染，选中发光 |
| 工作台 | 属性面板 | 标签+输入框行，值范围滑块 |
| 教程弹层 | 高亮+提示 | 黄色脉动边框高亮，黄色气泡提示文字 |
| 暂停弹层 | 暂停弹窗 | 半透明遮罩+居中卡片，两个按钮 |
| 设置弹层 | 设置表单 | 分组设置项，快捷键编辑，关闭按钮 |
| 结算弹层 | 通关卡片 | 星级评分+统计数据+继续按钮 |

### 4.3 响应式

- 桌面优先设计，画布区域自适应填充剩余空间
- Canvas尺寸跟随容器resize
- 属性面板可收起
- 触摸操作支持（触摸拖拽、双指缩放）

### 4.4 动画效果

- 元件拖拽放置时的缩放弹跳
- 灯泡亮灭时的径向渐变辉光
- 导线有电流时的虚线流动动画
- 开关切换的旋转动画
- 教程高亮的脉动边框
- 结算页面的星级弹出动画
