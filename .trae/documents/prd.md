## 1. 产品概述
仓库 SKU 周转与滞销分析平台，面向供应链分析师，解决 Excel 查看总数无法解释变化原因的问题。通过入库、出库、库龄、批次、退货和安全库存六大数据源，提供多维筛选、可视化漏斗、库龄分布、周转排行、补货建议及自动周报，帮助分析师快速定位滞销风险与补货时机。

- 目标用户：供应链分析师、仓库经理、采购决策者
- 核心价值：将分散的库存数据转化为可操作的分析洞察，支持同 SKU 不同批次独立分析、近效期预警、异常标注，避免图表结论被误读

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 供应链分析师 | 管理员分配账号 | 查看全量数据、导出报告、配置筛选口径 |
| 仓库经理 | 管理员分配账号 | 查看本仓库数据、查看周报、导出 CSV |
| 系统管理员 | 默认账号 | 全部权限、用户管理、数据字典维护 |

### 2.2 功能模块
1. **分析仪表盘页**：多维筛选面板、库存漏斗图、库龄分布图、周转排行、补货建议、近效期提醒、异常点标注
2. **数据管理页**：批量导入（CSV）、数据字典查看、缺失值处理配置、权限过滤设置
3. **周报中心页**：周报列表、自动生成报告、同比环比对比、异常点汇总、筛选口径记录、PDF/图片导出
4. **维度校验与下钻页**：关键维度校验口径定义、下钻路径配置、校验结果展示、导出

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 分析仪表盘 | 筛选面板 | 按 SKU、仓位、供应商、批次号、库龄区间筛选，支持组合筛选与一键重置 |
| 分析仪表盘 | 库存漏斗 | 从总入库→当前库存→有效周转→快速周转逐级递减，展示各环节转化率 |
| 分析仪表盘 | 库龄分布 | 按库龄区间（0-30天/30-60天/60-90天/90-180天/180天+）分布的堆叠柱状图，按批次拆分 |
| 分析仪表盘 | 周转排行 | SKU 周转率 TOP/BOTTOM 排行，同 SKU 不同批次分开计算，支持排序切换 |
| 分析仪表盘 | 补货建议 | 基于安全库存与当前库存差距，生成补货优先级列表与建议补货量 |
| 分析仪表盘 | 近效期提醒 | 近效期批次独立提醒卡片，含效期倒计时、SKU 信息、占比 |
| 分析仪表盘 | 异常标注 | 图表异常点自动标注（周转骤降、库存激增等），点击查看原因 |
| 数据管理 | 批量导入 | 拖拽上传 CSV 文件，自动解析入库/出库/库龄/批次/退货/安全库存六类数据 |
| 数据管理 | 数据字典 | 展示所有字段定义、类型、取值范围、业务含义 |
| 数据管理 | 缺失值处理 | 配置各字段缺失值策略（忽略/填充默认值/标记异常） |
| 数据管理 | 权限过滤 | 按角色配置可见数据范围（仓库/供应商/SKU 分类） |
| 周报中心 | 周报列表 | 按周展示历史报告，含生成时间、关键指标变化摘要 |
| 周报中心 | 报告详情 | 本周关键变化、同比环比、异常点汇总、筛选口径快照 |
| 周报中心 | 导出功能 | 导出为 PDF 或长图片，保留图表与数据完整性 |
| 维度校验 | 校验口径 | 定义周转率、库龄、安全库存等关键指标的计算口径与校验规则 |
| 维度校验 | 下钻路径 | 配置从汇总到明细的下钻路径（如按 SKU→批次→仓位） |
| 维度校验 | 校验结果 | 展示口径校验通过/未通过的指标，支持导出校验报告 |

## 3. 核心流程

### 3.1 日常分析流程
用户进入仪表盘 → 选择筛选条件（SKU/仓位/供应商/批次/库龄）→ 查看库存漏斗与库龄分布 → 发现异常点点击查看详情 → 下钻至批次级别 → 查看近效期提醒 → 根据补货建议决策 → 导出分析结果

### 3.2 周报生成流程
系统每周自动触发 → 汇总本周数据变化 → 计算同比环比 → 识别异常点 → 记录当前筛选口径 → 生成周报草稿 → 分析师确认后归档 → 可导出 PDF/图片

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深蓝灰 (#1B2A4A) + 橙色强调 (#FF6B35) + 青绿辅助 (#2ECDA7)
- 按钮：圆角矩形，带微阴影，hover 态加深
- 字体：标题用 DM Sans（粗体），正文用 Noto Sans SC
- 布局：左侧固定导航 + 右侧内容区，卡片式模块布局
- 图标风格：线性图标，统一 20px 描边

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 分析仪表盘 | 筛选面板 | 顶部固定栏，下拉选择器 + 日期范围 + 重置按钮，深色背景 |
| 分析仪表盘 | 库存漏斗 | 居中大卡片，ECharts 漏斗图，带转化率标注，hover 显示明细 |
| 分析仪表盘 | 库龄分布 | 左侧卡片，ECharts 堆叠柱状图，按批次颜色拆分，legend 可筛选 |
| 分析仪表盘 | 周转排行 | 右侧卡片，水平条形图，TOP 标橙色、BOTTOM 标红色，点击下钻 |
| 分析仪表盘 | 补货建议 | 底部表格卡片，优先级色标，建议补货量高亮，支持排序 |
| 分析仪表盘 | 近效期提醒 | 右侧浮动卡片组，红色/黄色预警色标，倒计时数字突出 |
| 分析仪表盘 | 异常标注 | 图表内红色虚线圈标注，tooltip 显示异常原因与建议 |

### 4.3 响应式
- 桌面优先设计，1920px 为基准宽度
- 平板适配（1024px）：筛选面板折叠为抽屉，图表改为纵向堆叠
- 移动端（768px 以下）：仅保留核心图表，筛选改为全屏弹窗
