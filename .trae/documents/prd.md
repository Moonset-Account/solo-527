## 1. 产品概述

音乐演出票务售卖站——面向活动主办方与内部运营人员的全流程票务管理平台。主办方完成选票、购票、退票；内部侧维护票种配置与库存，追踪票务收入异常到责任人，支持常用筛选保存、到场缺口提醒与批量操作追溯。

- 解决票务售卖流程分散、收入异常难以追责、操作不可追溯等问题
- 目标用户：活动主办方（外部）、内部运营/管理员（内部）

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 活动主办方 | 邮箱注册/邀请码 | 浏览演出、选票购票、申请退票、查看订单 |
| 内部运营 | 管理员创建 | 配置票种与库存、审核报名、管理分组赛程、处理退票、查看收入报表 |
| 管理员 | 系统初始化 | 全部权限、异常追踪定位、批量操作、系统配置 |

### 2.2 功能模块

1. **演出大厅页**：演出列表、搜索筛选、票种展示、快速购票
2. **购票流程页**：选座/选票种、订单确认、支付、出票
3. **订单管理页**：我的订单、退票申请、退票记录
4. **票种库存管理页**：票种配置、库存设置、库存变动日志
5. **报名审核页**：报名列表、审核操作、批量审核、保存筛选
6. **分组赛程页**：赛程分组、排期管理、保存筛选
7. **收入分析页**：收入总览、异常标记、责任人定位、趋势图表
8. **到场管理页**：到场签到、缺口提醒、报名质量分析
9. **批量操作页**：批量退票、批量审核、操作追溯日志
10. **仪表盘页**：关键指标、待办事项、异常告警

## 3. 核心流程

### 3.1 购票流程

主办方浏览演出 → 选择票种和数量 → 确认订单信息 → 模拟支付 → 出票 → 收到确认通知

### 3.2 退票流程

主办方提交退票申请 → 内部运营审核 → 审核通过后退款 → 库存回补 → 收入记录更新

### 3.3 异常追踪流程

系统检测收入异常（退款率飙升/单笔大额退款等）→ 标记异常订单 → 定位操作人 → 通知管理员

### 3.4 批量操作流程

运营选择批量操作类型 → 选择目标数据 → 确认执行 → 系统记录发起人与时间 → 执行处理 → 生成结果报告

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深紫 #6C3CE1（音乐/舞台感）+ 琥珀 #F59E0B（强调/CTA）
- 辅助色：暗灰 #1E1E2E（背景）、浅灰 #F8F9FA（卡片）、翡翠 #10B981（成功状态）
- 按钮风格：圆角 8px，主按钮填充色、次按钮描边，hover 微抬升 + 阴影
- 字体：标题用 Noto Serif SC（衬线，文化感），正文用 Noto Sans SC（无衬线，可读性）
- 布局：左侧导航栏 + 右侧内容区，卡片式内容块
- 图标风格：线性图标（Lucide 风格），2px 描边

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 演出大厅页 | 演出列表 | 网格卡片布局，封面图+标题+日期+最低价，筛选侧栏 |
| 购票流程页 | 选票确认 | 步骤条（1-2-3），票种选择卡，数量选择器，订单摘要面板 |
| 订单管理页 | 订单列表 | 表格布局，状态标签（彩色胶囊），操作按钮组 |
| 票种库存管理页 | 库存管理 | 卡片+进度条展示库存，筛选栏带保存按钮 |
| 报名审核页 | 审核列表 | 表格+复选框，批量操作栏浮动，筛选栏带保存按钮 |
| 收入分析页 | 收入总览 | 统计卡片+折线图+环形图，异常行高亮红框 |
| 到场管理页 | 签到管理 | 签到卡列表，缺口告警横幅，质量趋势折线图 |
| 批量操作页 | 操作追溯 | 时间线布局，操作人头像+名称，结果统计饼图 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1024px
- 平板适配：导航栏折叠为汉堡菜单，卡片从三列变两列
- 移动端适配：单列布局，底部操作栏固定

### 4.4 动效设计

- 页面切换：Hotwire Turbo 渐入过渡
- 卡片悬停：微抬升 + 阴影扩展
- 数据加载：骨架屏占位
- 签到成功：绿色对勾弹出动画
- 异常告警：脉冲红点 + 闪烁边框
