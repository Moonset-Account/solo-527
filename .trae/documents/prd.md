## 1. 产品概述

洗车店线上预约收银系统——将顾客预约与支付、门店技师工位调度、车辆档案管理、收银单据生成与到店转化报表整合至一体化平台，减少值班人员跳转操作，保障配件缺货状态实时同步至技师产能，所有状态变更写入日志以支持交接复盘。

- 目标用户：洗车店顾客（线上预约支付）、值班人员（门店运营管理）、门店负责人（报表决策）
- 核心价值：线上化收银预约降低排队流失，一体化仪表盘减少操作跳转，状态日志保障交接可追溯

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 顾客 | 手机号注册/微信授权 | 浏览服务套餐、在线预约、在线支付、查看订单 |
| 值班人员 | 管理员分配账号 | 接单调度、安排技师工位、查看会员套餐、备注处理 |
| 门店负责人 | 管理员分配账号 | 报表查看、配件缺货处理、技师产能分析、系统配置 |

### 2.2 功能模块

1. **顾客预约页**：服务套餐浏览、时段选择、在线支付、订单状态跟踪
2. **门店仪表盘**：今日预约总览、技师工位状态、会员套餐快捷查看、试驾时间、备注与关键字段同屏
3. **技师工位调度**：工位看板、技师排班、产能日历
4. **车辆档案管理**：车辆信息录入、历史服务记录、备注标签
5. **收银单管理**：收银单生成、支付状态追踪、退款处理
6. **配件缺货处理**：缺货登记、处理节点跟踪、同步至技师产能报表
7. **到店转化报表**：预约到店率、服务转化漏斗、技师绩效统计
8. **状态变更日志**：全流程状态变更记录、操作人追踪、交接复盘时间线

## 3. 核心流程

顾客线上预约支付流程：顾客选择服务套餐 → 选择预约时段 → 提交预约 → 在线支付 → 系统生成订单 → 值班人员收到新预约通知 → 安排技师与工位 → 顾客到店 → 技师开始服务 → 服务完成 → 生成收银单 → 状态记录日志。

配件缺货同步流程：技师发现配件缺货 → 登记缺货信息 → 系统自动标记受影响工位产能下降 → 负责人下单采购 → 更新处理节点（已下单→在途→到货→上架）→ 配件到货恢复 → 系统自动恢复技师产能 → 全程状态变更写入日志。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深海蓝 (#0F2B46) + 活力橙 (#FF6B35) 强调色，传达专业与高效
- 辅助色：浅灰底 (#F5F6FA)、白卡片 (#FFFFFF)、状态绿 (#22C55E)、告警红 (#EF4444)
- 按钮风格：圆角 8px，主按钮实色填充，次按钮描边，悬浮阴影反馈
- 字体：标题使用 Noto Sans SC Bold，正文使用 Noto Sans SC Regular，数字/金额使用 JetBrains Mono
- 布局风格：左侧固定导航 + 顶部面包屑，内容区卡片式网格布局
- 图标风格：线性图标 (Lucide Icons)，2px 描边，统一 20px 尺寸

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 顾客预约页 | 服务套餐列表 | 卡片网格，每卡含图标、名称、价格、时长、预约按钮 |
| 顾客预约页 | 时段选择器 | 7日横排日历 + 下方时段网格，已满灰色，可用绿色 |
| 顾客预约页 | 在线支付 | 底部抽屉式支付面板，订单摘要 + 支付按钮 |
| 门店仪表盘 | 今日预约总览 | 顶部统计卡片(总数/已到/服务中/已完成) + 下方列表 |

| 门店仪表盘 | 会员套餐快览 | 右侧滑出面板，显示会员等级、剩余次数、有效期 |

### 4.3 响应式策略

- 桌面优先设计，最小宽度 1280px 全功能展示
- 平板端(768-1279px)仪表盘切换为标签页模式，减少同屏信息密度
- 移动端(<768px)顾客预约页自适应，门店后台仅提示"请在电脑端操作"
