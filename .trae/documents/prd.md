## 1. 产品概述
IT 账号资产配置库是面向 IT 部门的资产与配置管理平台，用于统一管理账号资产、配置项、变更工单和故障处理全流程。目标用户为 IT 主管、值班工程师和系统管理员，核心价值在于确保资产配置变更可追溯、操作可审计、处理时效可量化。

- 解决 IT 资产配置分散、变更无记录、故障处理不透明的问题
- 为 IT 主管提供单据级别的完整审计时间线，确保准确性和合规性

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| IT 主管 | 管理员分配 | 查看所有工单和审计日志、审批变更、导出报表、查看处理时效 |
| 值班工程师 | 管理员分配 | 提交申请/故障工单、处理指派工单、更新资产和配置项 |
| 管理员 | 系统初始化 | 用户管理、角色分配、系统配置、全量数据操作 |

### 2.2 功能模块
1. **工单管理**：提交申请和故障工单，工单列表、筛选、详情查看
2. **资产配置管理**：资产台账、配置项维护、资产与配置项关联
3. **变更时间线**：回滚方案、漏洞修复、资产配置变更形成单据详情内一条时间线
4. **角色权限控制**：值班工程师/管理员权限区分，变更失败动作留日志
5. **处理时效明细**：工单各阶段处理时间记录、SLA 达标统计
6. **导出与审计**：下载结果保留查询口径和导出人信息，确保报表可对账

## 3. 核心流程

### 3.1 工单处理流程
值班工程师提交申请/故障工单 → 工单分配给处理人 → 处理人执行变更（关联回滚方案、漏洞修复、资产配置） → 变更失败时自动记录失败日志 → IT 主管审批确认 → 工单关闭。全流程在工单详情页以时间线形式展示。

### 3.2 变更审计流程
任何变更动作触发日志记录 → 日志包含操作人、操作时间、操作类型、变更前后数据 → 变更失败动作单独标记 → IT 主管可按时间线回看完整处理链路。

### 3.3 导出审计流程
用户选择查询条件 → 执行查询 → 触发导出 → 导出文件记录查询口径参数和导出人信息 → 导出结果可在导出中心回溯。

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深蓝灰 (#1e293b) + 科技蓝 (#3b82f6) 点缀，传达专业和可信感
- 辅助色：成功绿 (#10b981)、警告橙 (#f59e0b)、危险红 (#ef4444)
- 按钮风格：圆角矩形 (rounded-lg)，主按钮填充色、次按钮描边

- 布局风格：左侧导航栏 + 顶部面包屑 + 内容区域，卡片式模块布局

## 5. 核心规则

### 5.1 变更失败日志规则
- 任何涉及变更的操作失败，必须记录到 audit_log 表
- 日志包含：操作人 ID、操作时间、操作类型、变更目标、失败原因、原始数据快照
- 失败日志在审计日志页以红色标签高亮显示

### 5.2 导出审计规则
- 每次导出生成 export_record 记录
- 记录包含：查询条件（JSON 格式）、导出人 ID、导出时间、文件名、数据条数
- 导出文件内包含查询口径水印和导出人信息页脚

### 5.3 时间线规则
- 回滚方案、漏洞修复、资产配置变更在工单详情页形成一条纵向时间线
- 时间线节点包含：操作人、操作时间、操作类型、操作结果
- IT 主管可在时间线中查看完整处理链路
