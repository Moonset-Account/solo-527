## 1. 产品概述

共享单车站点调度分析仪表盘——面向城市出行运营团队的数据可视化决策平台。整合骑行起终点、站点余量、早晚高峰、维修车辆和天气数据，通过地图流向、峰值预测、站点告警和调度效果对比四大核心视图，帮助运营人员快速识别供需失衡、预判高峰压力、衡量调度成效，并每周自动生成可下载的分析报告。

- 核心用户：城市共享单车运营调度团队
- 核心价值：将分散数据转化为可操作调度决策，缩短从"发现问题"到"执行调度"的响应时间

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 运营分析师 | 内部分配账号 | 浏览仪表盘、调整筛选器、生成与下载周报 |
| 调度管理员 | 内部分配账号 | 浏览仪表盘、调整筛选器、生成与下载周报、查看调度明细追溯 |

### 2.2 功能模块

1. **调度分析仪表盘**：全局筛选器面板、Mapbox 地图流向视图、D3 峰值预测图、站点告警列表、调度效果对比图、时间窗口切换、样本量提示
2. **周报中心**：周报自动生成预览、关键变化摘要、同比环比指标、异常点标注、筛选口径快照、PDF/图片导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 调度分析仪表盘 | 全局筛选器面板 | 站点多选、线路筛选、时间段切换（早高峰/晚高峰/全天/自定义）、车辆状态过滤（可调度/维修中/全部）、调度记录范围、天气条件筛选；筛选状态贯穿所有图表联动 |
| 调度分析仪表盘 | Mapbox 地图流向视图 | 站点标记（余量色阶）、骑行流向弧线（粗细表流量）、早晚高峰切换、点击站点弹出详情（余量/流入流出/维修车辆数）、流向动画 |
| 调度分析仪表盘 | D3 峰值预测图 | 折线图展示历史+预测骑行量、置信区间阴影、早晚高峰标注、天气影响叠加层、时间窗口切换 |
| 调度分析仪表盘 | 站点告警列表 | 余量不足告警（红/黄/绿）、维修车辆占比过高告警、供需失衡告警、告警级别排序、点击跳转地图定位 |
| 调度分析仪表盘 | 调度效果对比图 | 调度前后余量对比柱状图、供需缺口变化趋势线、调度响应时间统计、按站点/线路分组对比 |
| 调度分析仪表盘 | 可追溯明细面板 | 当前筛选条件下的骑行记录明细表、调度记录明细表、支持分页与排序 |
| 周报中心 | 周报预览 | 本周关键变化摘要卡片、同比环比指标表格、异常点高亮列表、筛选口径快照 |
| 周报中心 | 导出功能 | 导出为 PDF、导出为图片（PNG）、报告内含图表截图与数据表格 |

## 3. 核心流程

用户打开仪表盘 → 通过全局筛选器设定关注范围（站点/线路/时间段/车辆状态）→ 地图流向视图实时联动展示骑行流向与站点状态 → 峰值预测图显示未来时段需求预判 → 站点告警列表突出异常站点 → 调度管理员参考告警与预测执行调度 → 调度效果对比图验证调度成效 → 每周自动生成周报 → 运营分析师下载周报归档

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深炭灰 (#1a1d23) 背景 + 电光青 (#00e5c7) 主强调色 + 琥珀橙 (#ff9f43) 告警色
- **次色调**：钢蓝 (#4a6fa5) 辅助数据色、翡翠绿 (#2ecc71) 正向指标、珊瑚红 (#e74c3c) 负向指标
- **按钮风格**：圆角微透明玻璃质感，hover 时提升亮度和阴影
- **字体**：JetBrains Mono 数据数字 + Noto Sans SC 中文正文
- **布局**：左侧筛选面板 + 中央地图主视图 + 右侧数据面板，底部明细表
- **图标**：Lucide 图标库线性风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 调度分析仪表盘 | 全局筛选器面板 | 左侧固定面板，多选下拉框、时间窗口按钮组、状态标签切换、天气条件复选框 |
| 调度分析仪表盘 | 地图流向视图 | 中央大面积 Mapbox 地图，站点圆形标记（色阶映射余量），弧线流向动画，右上角图例 |
| 调度分析仪表盘 | 峰值预测图 | 右上区域 D3 折线图，置信区间半透明阴影，高峰时段背景色带 |
| 调度分析仪表盘 | 站点告警列表 | 右侧告警卡片列表，红/黄/绿左边框，脉冲动画标识紧急告警 |
| 调度分析仪表盘 | 调度效果对比 | 右下区域分组柱状图+趋势线组合图 |
| 调度分析仪表盘 | 明细面板 | 底部可折叠表格，分页器，列头排序 |
| 周报中心 | 周报预览 | 全页报告布局，指标卡片行、图表区、异常列表、筛选口径信息栏 |
| 周报中心 | 导出按钮 | 右上角固定导出菜单，PDF 和 PNG 选项 |

### 4.3 响应式

- 桌面优先设计，1920×1080 为最佳视口
- 1440px 以下：右侧面板折叠为底部标签页
- 1024px 以下：筛选面板收起为顶部汉堡菜单
- 表格组件内置横向滚动

### 4.4 数据状态设计

- **加载态**：骨架屏（skeleton）+ 脉冲动画
- **空数据态**：插画 + 提示文案 + 建议操作按钮
- **样本量不足**：图表上方黄色提示条 "当前筛选条件下样本量仅 N 条，结果可能不具统计意义"
- **维修车辆剔除**：筛选器明确显示 "已从可调度库存中剔除 N 辆维修车辆"
- **导出处理**：导出时若存在空值字段，PDF 中以 "—" 标记并在页脚注明空值数量
