## 1. 产品概述

古诗词词牌拼接游戏是一款面向学生的文字益智游戏，玩家根据平仄规律、意象关联和提示信息，将散落的字词拼成正确的诗句，逐步解锁词牌背后的故事与文化。通过渐进式关卡设计引入新规则，帮助学生在趣味中掌握古诗词知识。

- 目标用户：中学生及古诗词爱好者
- 核心价值：以游戏化方式学习词牌知识，培养平仄语感和意象理解力

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 学生 | 本地免注册 | 游玩关卡、查看学习卡、查看统计数据 |
| 访客 | 无需注册 | 试玩前几关 |

### 2.2 功能模块

1. **主界面**: 游戏标题、开始按钮、继续游戏、设置入口
2. **关卡选择页**: 词牌章节列表、进度显示、星级评价
3. **游戏页面**: Canvas 画布、字词拖拽区、提示面板、平仄对照、计时器
4. **结算页面**: 评分详情、用时统计、失败次数、星级评定、学习卡解锁
5. **学习卡页面**: 词牌知识卡片、诗句赏析、平仄标注
6. **设置页面**: 音效开关、帧率显示、输入重映射、存档管理

## 3. 核心流程

玩家从主界面进入，选择章节和关卡后进入游戏。游戏中根据平仄规律和意象提示，将散落字词拖拽到正确位置拼成诗句。拼错时系统给出原因解释（平仄不符、意象不搭、字序错误等），帮助理解。正确完成后进入结算，根据用时、提示使用、失败次数评星，同时解锁词牌故事和学习卡。逐步推进解锁新章节，新章节引入新规则（如对仗要求、押韵限制等）。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：墨黑(#1a1a2e) + 宣纸米(#f5f0e8)
- 辅助色：朱砂红(#c0392b)用于强调和选中态、靛青(#2c6e8a)用于平仄标注
- 字体：标题使用楷体风格字体，正文使用宋体风格
- 按钮风格：圆角矩形，水墨晕染边框效果，悬浮时墨迹扩散动画
- 布局风格：竖版卷轴式，章节地图采用山水画卷横向展开
- 图标风格：毛笔笔触风格的手绘图标
- 背景纹理：宣纸质感 + 淡雅山水画元素

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 主界面 | 标题动画 | 大号楷体标题、墨迹渲染动画、飘落花瓣粒子 |
| 主界面 | 菜单区 | 竖排按钮、毛笔笔触图标、水墨边框 |
| 关卡选择 | 章节地图 | 横向卷轴、山水路径、节点图标、锁链遮罩 |
| 游戏页面 | Canvas 画布 | 宣纸底色、墨迹字卡、朱砂高亮、毛笔光标 |
| 游戏页面 | 提示面板 | 卷轴展开式、灯台图标 |
| 游戏页面 | 错误弹窗 | 红色墨迹边框、错误原因文字、鼓励语句 |
| 结算页面 | 评星动画 | 金色星辉、墨迹绽放、卷轴展开 |
| 学习卡 | 卡片网格 | 竹简样式卡片、书签标签、翻页动画 |
| 设置页面 | 设置列表 | 竖排竹简式列表、开关按钮 |

### 4.3 响应式设计

- 桌面优先设计，最小支持 1024x768
- 游戏画布根据窗口自适应缩放
- 移动端适配：触控拖拽替代鼠标拖拽
- 平板端优化：分屏布局（左画布右提示）

### 4.4 Canvas 场景指导

- 环境：宣纸纹理底色，淡墨山水远景
- 光照：柔和暖光模拟烛光/灯笼照明
- 交互：字卡拖拽时产生墨迹拖尾效果，放置正确时墨花绽放
- 动画：字卡入场（从墨滴化开）、错误时抖动+墨渍溅射、完成时卷轴展开
- 后处理：边缘暗角、纸纹叠加、墨迹晕染效果
