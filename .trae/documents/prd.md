## 1. 产品概述

装修客户现场巡检系统，面向装修公司老板及内部团队，用于管理装修合同、分派巡检任务、跟踪客户满意度，并提供施工质量报表和节点延期提醒。通过看板式界面实现巡检进度可视化，配置区支持验收反馈、预算版本和巡检任务的灵活调整，并完整记录变更审计日志。

- 目标用户：装修公司管理者、巡检员、材料员、客户
- 核心价值：提升巡检效率、降低延期风险、增强客户信任、支撑月底复盘

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 管理员 | 系统预设 | 全部功能，含配置管理和演示数据清理 |
| 巡检员 | 管理员创建 | 查看方案、执行巡检任务、提交巡检记录 |
| 材料员 | 管理员创建 | 接收节点延期提醒、查看物料需求 |
| 客户 | 合同关联邀请 | 查看巡检进度、提交满意度反馈 |

### 2.2 功能模块

1. **工作台**：核心数据概览、待办提醒、延期预警
2. **方案查看**：装修方案详情浏览、方案关联合同和任务
3. **合同管理**：合同 CRUD、合同状态跟踪、合同关联方案
4. **巡检任务**：任务分派、任务执行、巡检记录提交
5. **满意度看板**：看板视图展示客户满意状态、提醒未反馈客户
6. **配置管理**：验收反馈模板、预算版本管理、巡检任务模板，变更审计日志
7. **质量报表**：施工质量统计、月度复盘报表、节点延期分析
8. **提醒中心**：节点延期提醒、巡检到期提醒、满意度催反馈
9. **演示管理**：一键清理演示数据、区分演示与真实数据

## 3. 核心流程

### 3.1 巡检任务流程

管理员创建合同后，根据装修方案关联巡检节点，分派巡检员执行。巡检员现场填写记录并提交验收，客户收到反馈邀请并评价。若节点延期则自动触发材料员提醒。

```mermaid
flowchart TD
    "创建合同" --> "关联方案"
    "关联方案" --> "生成巡检节点"
    "生成巡检节点" --> "分派巡检员"
    "分派巡检员" --> "现场巡检"
    "现场巡检" --> "填写巡检记录"
    "填写巡检记录" --> "提交验收"
    "提交验收" --> "客户反馈"
    "客户反馈" --> "更新满意度看板"
    "生成巡检节点" --> "节点延期检测"
    "节点延期检测" --> "提醒材料员"
```

### 3.2 配置变更审计流程

```mermaid
flowchart TD
    "管理员进入配置区" --> "修改验收反馈/预算版本/任务模板"
    "修改验收反馈/预算版本/任务模板" --> "记录变更日志（操作人+时间+内容）"
    "记录变更日志（操作人+时间+内容）" --> "配置生效"
```

### 3.3 月底复盘流程

```mermaid
flowchart TD
    "系统汇总月度数据" --> "生成质量报表"
    "生成质量报表" --> "延期节点分析"
    "延期节点分析" --> "满意度统计"
    "满意度统计" --> "管理层数据复盘"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝 #1B2A4A（专业稳重）、辅助色：琥珀 #E8A838（警示提醒）、成功绿 #36B37E
- 按钮风格：圆角 6px，扁平化 + 悬浮阴影
- 字体：系统字体栈，标题 18px/16px，正文 14px，辅助 12px
- 布局风格：左侧导航 + 右侧内容区，卡片式模块
- 图标风格：线性图标，统一 20px 尺寸

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 登录页 | 登录表单 | 居中卡片、Logo、输入框、按钮 |
| 工作台 | 数据卡片行 | 四列统计卡片（图标+数字+趋势） |
| 工作台 | 延期预警 | 红色标签列表、快捷通知按钮 |
| 方案查看 | 方案列表 | 网格卡片、缩略图、状态标签 |
| 合同管理 | 合同表格 | 数据表格、状态筛选标签页、操作按钮 |
| 巡检任务 | 任务看板 | 四列看板、拖拽卡片、人员头像 |
| 满意度看板 | 状态列 | 四列看板（未反馈/满意/一般/不满意）、客户卡片 |
| 配置管理 | 配置表格 | 表格+侧滑编辑面板、变更日志时间线 |
| 质量报表 | 图表区 | 柱状图、饼图、折线图、数据表格 |
| 演示管理 | 清理面板 | 大号清理按钮、确认弹窗、清理进度提示 |

### 4.3 响应式设计

桌面优先设计，支持 1280px+ 主屏幕。平板端自动折叠侧边栏为抽屉模式，移动端暂不作为优先适配目标。

## 5. 非功能需求

- 演示数据与真实数据通过 `is_demo` 标记区分，一键清理仅删除演示数据
- 配置变更必须记录操作人、操作时间、变更前后内容
- 节点延期提醒通过 Celery 异步任务检测并推送
- 所有 API 接口需支持分页、排序、筛选
