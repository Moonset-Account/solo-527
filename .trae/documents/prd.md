## 1. 产品概述

外卖商户出餐时长监控系统，用于运营人员监控商圈内商户的备餐和骑手等待时长，通过多维度数据分析优化出餐效率，提升用户体验。

- 核心目标：拆分商户备餐与骑手等待时长，定位出餐瓶颈，辅助运营决策
- 目标用户：外卖平台运营人员、商圈经理、商户运营专员
- 产品价值：数据驱动的出餐效率优化，减少用户等待时间，降低退款率

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 运营人员 | 账号密码登录 | 查看商圈地图、商户详情、导出报表、添加整改备注 |
| 管理员 | 账号密码登录 | 所有运营权限 + 系统配置、用户管理 |

### 2.2 功能模块

1. **商圈地图页**：商圈热力分布、商户出餐排行、筛选过滤、数据概览
2. **商户详情页**：订单时间轴、出餐时长趋势、整改备注、异常样本、维度分析
3. **数据报表页**：综合报表、导出功能、超时原因聚合

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 商圈地图页 | 数据概览卡片 | 展示商圈整体指标：平均备餐时长、平均等待时长、订单量、退款率 |
| 商圈地图页 | 商圈热力地图 | 按区块展示出餐效率热力分布，支持缩放拖拽 |
| 商圈地图页 | 商户排行榜 | 按出餐时长/等待时长/订单量排序，支持快速跳转详情 |
| 商圈地图页 | 筛选工具栏 | 时间范围、天气、爆单时段筛选 |
| 商户详情页 | 核心指标卡片 | 接单-备餐、备餐-骑手到店、骑手到店-取餐、取餐-送达各环节平均时长 |
| 商户详情页 | 出餐时长趋势图 | 近7/30天备餐时长与骑手等待时长趋势对比 |
| 商户详情页 | 订单时间轴 | 展示最近订单各节点时间戳，高亮异常订单 |
| 商户详情页 | 整改备注管理 | 保留最近三次整改记录，支持对比整改前后数据 |
| 商户详情页 | 异常样本下钻 | 超时订单明细，支持查看骑手备注、退款原因 |
| 商户详情页 | 辅助维度分析 | 天气影响、时段分布、骑手等餐备注词云 |
| 数据报表页 | 超时原因聚合 | 饼图/柱状图展示各类超时原因占比 |
| 数据报表页 | 导出报表 | 支持 Excel/CSV 格式导出订单明细和统计报表 |

## 3. 核心流程

运营人员登录系统后，首先查看商圈地图了解整体出餐情况，通过排行榜或地图定位问题商户，进入商户详情页深入分析各环节时长，查看异常样本和整改记录，必要时添加整改备注，最后可导出报表进行复盘。

```mermaid

    A["登录系统"] --> B["查看商圈地图"]
    B --> C["筛选条件<br/>时间/天气/时段"]
    C --> D["查看商户排行榜"]
    D --> E["进入商户详情"]
    E --> F["分析各环节时长"]
    F --> G["查看异常样本"]
    G --> H["查看整改记录"]
    H --> I["添加整改备注"]
    I --> J["对比整改前后数据"]
    J --> K["导出报表"]
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深蓝色 (#165DFF) - 代表专业、数据、可信赖
- **辅助色**：橙色 (#FF7D00) - 用于警告、异常指标高亮
- **成功色**：绿色 (#00B42A) - 正常指标
- **危险色**：红色 (#F53F3F) - 严重超时、退款
- **中性色**：深灰 (#1D2129)、中灰 (#4E5969)、浅灰 (#C9CDD4)、背景 (#F2F3F5)

- **按钮风格**：圆角 6px，主按钮蓝色填充，次要按钮白色描边
- **字体**：PingFang SC / Microsoft YaHei，标题 16-20px，正文 14px，辅助文字 12px
- **布局风格**：卡片式布局，顶部导航 + 侧边筛选 + 主内容区
- **图标风格**：线性图标，简洁清晰，使用 Lucide Icons

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 商圈地图页 | 数据概览 | 4 个指标卡片横向排列，数值大号字体展示，趋势小图表 |
| 商圈地图页 | 热力地图 | 地图为主视觉，右侧悬浮排行榜，筛选栏在顶部 |
| 商圈地图页 | 排行榜 | 表格形式，支持列排序，行 hover 高亮，点击跳转 |
| 商户详情页 | 指标卡片 | 时间轴式布局，展示各环节流转，关键路径高亮 |
| 商户详情页 | 趋势图 | ECharts 折线图，双 Y 轴对比备餐与等待时长 |
| 商户详情页 | 订单列表 | 带时间轴的订单列表，异常订单边框高亮 |
| 商户详情页 | 整改备注 | 卡片堆叠展示，新旧对比按钮醒目 |
| 数据报表页 | 聚合图表 | 多图表布局，支持切换图表类型 |

### 4.3 响应式
- 桌面端优先设计，最低支持 1280px 宽度
- 侧边栏在小屏幕可折叠
- 表格支持横向滚动

### 4.4 动效设计
- 页面加载：卡片渐入 + 轻微上移动画
- 图表加载：数据从 0 到目标值的过渡动画
- Hover 效果：卡片轻微上浮 + 阴影加深
- 数据更新：数值变化时的平滑过渡
