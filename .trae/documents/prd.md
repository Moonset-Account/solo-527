## 1. 产品概述

事项闭环台（内部称"周会事项复盘库"）是面向行政负责人日常事务管理的全流程闭环平台。核心解决周会事项从创建、认领、推进到复盘结论归档的完整链路，确保每一条事项有归属、有进度、有结论。
- 目标用户：行政负责人、项目经理（PM）、系统管理员
- 产品价值：消除事项流转中的信息断层，实现逾期自动预警、责任归属可追溯、复盘结论可归档

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 项目经理（PM） | 管理员分配账号 | 认领/创建待办、补充进度、查看复盘结论、配置页只读部分字段 |
| 管理员 | 系统初始化 | 全部权限：用户管理、配置页全部字段、复盘结论编写、责任归属统计、操作日志查看 |

### 2.2 功能模块

1. **首页**：待办看板、异常（逾期）明细、快捷认领入口、进度补充入口
2. **事项管理页**：事项列表、筛选/搜索、事项详情（含进度时间线）
3. **运营后台页**：复盘结论整理、责任归属统计图表、逾期率统计
4. **配置页**：系统开关、复盘结论模板、责任部门管理、附件版本管理、变更记录
5. **用户管理页**（管理员）：账号增删改、角色分配

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 首页 | 待办看板 | 按状态分组展示待办事项，支持一键认领 |
| 首页 | 异常明细 | 展示逾期事项列表，标红高亮，支持快速跳转详情 |
| 首页 | 快捷操作 | 认领待办按钮、补充进度入口，无需进入详情页即可操作 |
| 事项管理 | 事项列表 | 多维度筛选（状态/部门/负责人/时间），搜索框，分页 |
| 事项管理 | 事项详情 | 事项基本信息、进度时间线、附件列表、操作日志 |
| 运营后台 | 复盘结论 | 按事项填写/编辑复盘结论，支持批量操作 |
| 运营后台 | 责任归属统计 | 按部门/负责人统计事项数、逾期数、闭环率 |
| 运营后台 | 逾期率统计 | 时间维度逾期率趋势图 |
| 配置页 | 系统开关 | 逾期预警开关、自动提醒开关等 |

| 配置页 | 责任部门管理 | 部门增删改，部门负责人绑定 |
| 配置页 | 附件版本管理 | 附件上传/替换/版本回溯 |
| 配置页 | 变更记录 | 记录每次配置修改的操作人、时间、字段、旧值/新值 |
| 用户管理 | 账号管理 | 创建/编辑/禁用用户账号，分配PM或管理员角色 |

## 3. 核心流程

**事项闭环主流程**：管理员或PM创建事项 → PM认领待办 → PM补充进度 → 事项完成/逾期 → 管理员整理复盘结论 → 配置页归档配置

```mermaid
flowchart TD
    "创建事项" --> "待认领"
    "待认领" --> "PM认领"
    "PM认领" --> "进行中"
    "进行中" --> "补充进度"
    "补充进度" --> "进行中"
    "进行中" --> "已完成"
    "进行中" --> "已逾期"
    "已逾期" --> "补充进度"
    "补充进度" --> "已完成"
    "已完成" --> "复盘结论"
    "复盘结论" --> "归档"
    "已逾期" --> "操作日志记录"
```

**逾期预警流程**：系统定时检查截止日期 → 事项逾期 → 自动标记逾期 → 记录逾期操作日志 → 首页异常明细展示

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝（#1E3A5F）+ 琥珀色强调（#F59E0B），传达专业与紧迫感
- 辅助色：浅灰背景（#F8FAFC），卡片白（#FFFFFF），逾期红（#EF4444），完成绿（#10B981）
- 按钮风格：圆角（8px），主按钮填充色，次按钮描边，hover 微抬升阴影
- 字体：思源黑体（Noto Sans SC），标题 18px/600，正文 14px/400，注释 12px/300
- 布局：左侧固定导航 + 右侧内容区，卡片式布局，顶部面包屑导航
- 图标风格：线性图标（Lucide），统一 20px，2px 描边

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 首页 | 待办看板 | 三列看板（待认领/进行中/已逾期），卡片拖拽，状态色标签 |
| 首页 | 异常明细 | 红色边框表格，逾期天数倒序，行点击跳转 |
| 首页 | 快捷操作 | 固定底部操作栏，认领按钮+进度输入框 |
| 事项管理 | 事项列表 | 筛选栏+数据表格+分页器，状态圆点指示 |
| 事项管理 | 事项详情 | 左侧信息面板+右侧时间线+底部附件区 |
| 运营后台 | 复盘结论 | 表格+行内编辑弹窗，下拉选择结论模板 |
| 运营后台 | 责任归属统计 | 饼图（按部门）+ 柱状图（按负责人） |
| 运营后台 | 逾期率统计 | 折线趋势图，周/月维度切换 |
| 配置页 | 系统开关 | Toggle 开关组，即时生效 |
| 配置页 | 变更记录 | 时间线样式，每条显示操作人+变更字段+新旧值对比 |
| 用户管理 | 账号管理 | 数据表格+新增弹窗，角色下拉选择 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1280px
- 平板端（768px-1280px）导航收起为汉堡菜单，表格横向滚动
- 移动端暂不支持，后台管理类产品以桌面使用为主
