## 1. 产品概述

网格事件闭环看板是面向社区网格员的日常运营管理工具，解决网格事件从上报到闭环全流程的跟踪与管控问题。目标用户为网格员、业务负责人和社区管理者，核心价值在于事件闭环可视化、重复上报智能识别与提醒、业务口径可编辑字典自主维护。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 网格员 | 管理员分配账号 | 上报事件、查看看板、投票、查看公示 |
| 业务负责人 | 管理员分配账号 | 维护字典值、配置提醒条件、管理规则、查看看板 |
| 社区管理者 | 管理员分配账号 | 全部权限，含事件督办与统计 |

### 2.2 功能模块

1. **事件闭环看板**：事件上报、地图定位、闭环状态流转、超时提醒
2. **整改复查**：整改指派、复查确认、闭环出问题自动提示
3. **字典管理**：设施照片分类、结果公示模板、议题投票选项，业务负责人可编辑维护
4. **规则管理**：字典值管理、提醒条件配置，调整后即时生效
5. **重复检测**：重复上报识别、提醒发出后回写设施完好数据

## 3. 核心流程

### 3.1 事件闭环流程

网格员上报事件 → 系统自动判定是否重复 → 非重复事件进入待整改 → 指派整改责任人 → 整改完成 → 复查确认 → 闭环。若复查不通过则退回整改环节。超时未闭环则自动提醒。重复上报则提醒并回写设施完好数据。

```mermaid
flowchart TD
    "网格员上报" --> "重复检测"
    "重复检测" -->|"非重复"| "待整改"
    "重复检测" -->|"重复"| "提醒+回写完好数据"
    "待整改" --> "指派整改责任人"
    "指派整改责任人" --> "整改中"
    "整改中" --> "复查确认"
    "复查确认" -->|"通过"| "闭环"
    "复查确认" -->|"不通过"| "整改中"
    "整改中" -->|"超时"| "超时提醒"
    "超时提醒" --> "整改中"
```

### 3.2 字典与规则管理流程

业务负责人进入规则页 → 选择字典类型 → 增删改字典值 → 保存 → 即时生效。配置提醒条件 → 保存 → Celery 立即按新规则执行。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝 (#1a365d) + 橙色警告 (#ed8936)，辅助色灰蓝 (#2d3748)
- 按钮风格：圆角 6px，主操作实色填充，次操作描边
- 字体：思源黑体 / Noto Sans SC，标题 20px 加粗，正文 14px 常规
- 布局风格：左侧导航 + 右侧内容区，卡片式布局
- 图标风格：线性图标，统一 20px

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 事件闭环看板 | 看板总览 | 深蓝色顶栏，4 张统计卡片（待整改/整改中/复查中/已闭环），橙色超时标记 |
| 事件闭环看板 | 事件上报表单 | 弹窗式表单，含定位地图、照片上传区、下拉选择事件类型 |
| 事件闭环看板 | 地图定位 | 全屏地图弹窗，支持点击标记和搜索 |
| 事件闭环看板 | 事件列表 | 表格布局，状态列带颜色标签，操作列含详情/指派按钮 |
| 整改复查 | 整改指派 | 侧滑抽屉面板，人员下拉选择+日期选择器 |
| 整改复查 | 复查确认 | 弹窗确认，通过/退回两个操作按钮 |
| 字典管理 | 字典列表 | 左侧分类树 + 右侧字典值表格，支持行内编辑 |
| 规则管理 | 规则配置 | 表单式配置，数值输入框+开关+保存按钮 |

### 4.3 响应式

桌面优先设计，平板横屏适配，关键操作区在移动端可用。

### 4.4 地图场景

- 使用高德地图 JS API 2.0，卫星+路网混合图层
- 事件标记使用自定义图标，按状态着色
- 点击标记弹出事件摘要气泡
