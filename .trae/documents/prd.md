## 1. 产品概述

实验预约数据登记站是一套面向科研实验室的综合管理平台，解决仪器台位预约冲突、实验数据散落、设备利用率不透明等核心痛点。目标用户包括一线实验人员、内部数据归档人员、实验室管理员及设备负责老师，旨在通过统一入口实现预约、归档、审批、看板的一站式闭环管理。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 一线实验人员 | 邮箱注册 / 邀请加入 | 预约仪器与台位、查看自己的预约记录、上传实验数据 |
| 内部归档人员 | 邮箱注册 / 邀请加入 | 归档实验数据、查看归档历史、导出数据 |
| 实验室管理员 | 管理员指派 | 审核权限、查样本去向、课题报表、管理仪器与台位 |
| 设备负责老师 | 管理员指派 | 接收仪器停用提醒、确认设备恢复、查看设备利用率 |

### 2.2 功能模块

1. **预约大厅**：仪器列表、台位日历视图、预约创建/取消/变更、冲突检测
2. **数据归档**：实验数据上传、元数据标注（课题、样本、处理状态）、归档检索
3. **接口状态看板**：系统 API 健康状态、第三方服务连通性、异常告警
4. **权限控制中心**：角色分配、权限审核流程、操作日志
5. **设备利用率看板**：设备使用率图表、停用提醒、恢复确认、趋势分析
6. **管理员面板**：样本去向追踪、课题统计报表、权限审核队列、多维筛选

## 3. 核心流程

### 3.1 仪器预约流程

一线实验人员登录系统 → 进入预约大厅 → 选择仪器与台位 → 查看可用时段 → 填写预约表单（含样本、课题信息） → 系统自动冲突检测 → 预约成功/提示冲突 → 预约记录出现在"我的预约"与管理员面板

### 3.2 数据归档流程

实验完成后 → 进入数据归档模块 → 上传实验文件 → 填写元数据（课题、样本、处理状态、责任人） → 归档入库 → 管理员可在归档列表检索 → 样本去向自动关联

### 3.3 设备停用与恢复流程

设备老师收到停用提醒 → 查看停用原因与影响范围 → 线下处理设备问题 → 在系统中确认恢复 → 设备状态更新为可用 → 利用率看板沉淀停用时段数据

### 3.4 权限审核流程

用户提交权限申请 → 进入管理员审核队列 → 管理员查看申请详情 → 审批/驳回 → 申请人收到通知 → 操作日志记录

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深青蓝 (#0F766E) + 琥珀橙 (#F59E0B) 点缀，体现科研严谨与活力
- **辅助色**：石板灰 (#1E293B) 背景、白色卡片、翡翠绿状态色
- **按钮风格**：圆角 8px，主操作实色填充，次要操作描边
- **字体**：标题用 Noto Sans SC Bold，正文用 Noto Sans SC Regular
- **布局风格**：左侧固定导航栏 + 右侧内容区，卡片式信息展示
- **图标**：Lucide Icons 线性风格，统一 20px

### 4.3 响应式设计

- 桌面优先设计，最小适配 1280px 宽度
- 导航栏在移动端折叠为汉堡菜单
- 日历视图在平板端切换为列表视图
- 表格在窄屏下支持横向滚动
- 筛选面板在移动端变为底部抽屉
