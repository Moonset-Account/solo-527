## 1. 产品概述

装修客户报价预算管理系统——面向装修公司的一站式业务承接平台。将报价预算从生成、版本管理、客户确认到售后闭环全流程数字化，帮助一线同事高效操作，老板实时掌控预算变更，月底复盘有据可依。

- 目标用户：装修公司老板、设计师/一线施工人员、装修客户
- 核心价值：减少一线操作跳转，预算变更实时提醒，售后数据可查可导出，移动端基础操作无障碍

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 公司老板 | 后台分配账号 | 查看所有预算、接收变更提醒、查看售后报表、导出数据 |
| 设计师/一线人员 | 后台分配账号 | 创建/编辑预算、上传材料清单与照片、管理合同附件 |
| 客户 | 邀请链接/短信 | 查看方案与合同、提交满意度反馈 |

### 2.2 功能模块

**前台（客户侧）**
1. **方案查看页**：客户查看装修方案详情、预算明细、材料清单
2. **合同查看页**：在线浏览合同内容、下载附件、确认签署
3. **满意度反馈页**：对施工阶段评分、文字反馈、提交记录

**管理端（公司内部）**
1. **工作台仪表盘**：项目概览、待办提醒、预算变更通知
2. **预算生成页**：创建新预算、添加材料与工艺项目、自动汇总
3. **版本管理页**：预算历史版本对比、版本回溯、变更记录
4. **客户满意度记录页**：查看客户反馈、导出满意度报表
5. **售后闭环报表页**：售后工单状态、闭环率统计、月度复盘数据导出

**一线操作专区**
1. **项目明细视图**：关键字段优先展示（项目名、面积、金额、状态），减少跳转
2. **材料清单面板**：内嵌在明细视图中，支持增删改、分类筛选
3. **现场照片面板**：内嵌在明细视图中，支持拍照上传、按区域分类
4. **合同附件面板**：内嵌在明细视图中，支持预览、下载、上传

## 3. 核心流程

**预算创建与确认流程**：设计师在管理端创建预算 → 系统自动生成版本V1 → 发送方案链接给客户 → 客户在前台查看方案 → 客户确认或提出修改 → 设计师修改预算 → 系统生成新版本V2并通知老板 → 老板审批 → 最终版本生成合同 → 客户签署确认。

**售后闭环流程**：施工完成 → 客户提交满意度反馈 → 系统记录并关联项目 → 如有问题则生成售后工单 → 一线人员处理 → 客户确认关闭 → 数据进入售后报表 → 月底复盘导出。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝 #1A365D（专业可信），辅助色：琥珀 #DD6B20（温暖提醒），成功色：翠绿 #38A169
- 按钮风格：圆角8px，主按钮填充深蓝，次要按钮描边，危险操作红色
- 字体：Noto Sans SC，标题18-24px，正文14px，辅助文字12px
- 布局风格：左侧导航 + 右侧内容区，卡片式内容组织
- 图标风格：Material Icons 填充风格，统一24px

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 工作台仪表盘 | 项目概览卡片 | 深蓝渐变卡片，白色数字，圆角12px |
| 工作台仪表盘 | 预算变更通知 | 右上角铃铛图标+红色角标，下拉通知列表 |
| 工作台仪表盘 | 待办事项 | 列表卡片，左侧状态色条，右侧操作按钮 |
| 预算生成页 | 预算项目编辑 | 可折叠分区，每行：项目名+金额+操作按钮 |
| 预算生成页 | 自动汇总 | 底部固定栏，分项合计+总价，琥珀色高亮变更 |
| 版本管理页 | 版本对比 | 左右分栏并排对比，变更项背景高亮 |
| 方案查看页（前台） | 预算明细 | 手风琴展开，材料明细缩进显示 |
| 合同查看页（前台） | 确认签署 | 底部固定大按钮，签署后显示绿色勾标 |
| 项目明细视图 | 关键字段区 | 顶部卡片：4列网格，标签+数值 |
| 项目明细视图 | 内嵌Tab面板 | Material Tab切换：材料/照片/附件 |
| 售后闭环报表页 | 工单看板 | 三列看板，卡片拖拽式交互 |

### 4.3 响应式设计

- 桌面优先设计，平板和手机浏览器自适应
- 导航栏：桌面端左侧固定，移动端底部Tab栏
- 明细视图：桌面端Tab横向排列，移动端垂直折叠
- 表格数据：桌面端完整表格，移动端卡片列表
- 照片上传：支持移动端相机调用，桌面端文件选择
- 所有按钮和可点击区域最小44px触控面积
- 关键操作（确认签署、提交反馈）移动端全宽按钮
