## 1. 产品概述

技术面试题库测评台是一个面向技术团队的面试管理平台，旨在将技术面试题库、测评流程、面试安排和录用决策统一纳入日常团队协作。平台解决的核心问题是：面试题库分散无标准、面试安排冲突频发、评分主观无据可依、面试质量无法量化追踪。

- **目标用户**：技术面试官、HR招聘团队、技术团队负责人
- **核心价值**：标准化技术面试流程，量化面试质量，减少面试冲突，提升招聘效率和公平性

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 面试官 | 管理员邀请 | 参与面试、填写评分、查看题库 |
| HR | 管理员邀请 | 安排面试、查看录用结果、导出报表 |
| 管理员 | 系统初始化 | 全部权限，包括题库管理、配置管理、看板访问 |
| 候选人 | 链接访问 | 完成测评、查看预约 |

### 2.2 功能模块

1. **前台（候选人端）**：在线测评、预约面试
2. **后台（管理端）**：题库管理、评分标准管理、面试安排、讲师档期、录用结果管理
3. **面试质量看板**：数据概览、预警中心、报表导出
4. **系统设置**：功能启停配置、修改记录、提醒规则

## 3. 核心流程

### 3.1 测评流程
候选人收到测评链接 → 进入测评页面 → 逐题作答 → 提交答卷 → 系统自动评分（客观题）→ 展示结果概览 → 引导预约面试

### 3.2 面试安排流程
HR创建面试需求 → 选择面试官 → 检测档期冲突 → 确认面试时间 → 发送提醒通知 → 面试官评分 → 录用决策

### 3.3 预警触发流程
系统定时扫描 → 检测到冲突/异常 → 按紧急程度分层 → 推送通知 → 在看板预警中心展示

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深蓝灰 (#1E293B) 搭配翡翠绿 (#10B981) 作为强调色，传达专业与可靠
- **辅助色**：琥珀色 (#F59E0B) 用于预警，珊瑚红 (#EF4444) 用于错误/紧急
- **按钮风格**：圆角 8px，主要操作实色填充，次要操作描边
- **字体**：标题使用 Source Serif 4，正文使用 DM Sans
- **布局风格**：侧边栏导航 + 内容区，卡片式模块布局
- **图标风格**：线性图标（Lucide），统一 20px 大小

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 候选人测评页 | 测评入口 | 居中卡片，渐变背景，倒计时器，进度条 |
| 候选人测评页 | 题目作答区 | 左侧题目列表导航，右侧作答区，代码编辑器风格 |
| 预约面试页 | 日程选择 | 日历网格，可用时段绿色高亮，选中态翡翠绿 |
| 后台首页 | 数据概览 | 四宫格指标卡片，趋势折线图，预警摘要 |
| 题库管理页 | 题目列表 | 表格布局，标签过滤栏，搜索框 |
| 题库管理页 | 题目编辑 | 分步表单，富文本编辑，实时预览 |
| 面试安排页 | 日历视图 | 全日历组件，拖拽交互，冲突红色标记 |
| 面试质量看板 | 指标概览 | 大数字卡片，雷达图，柱状图 |

| 系统设置页 | 功能启停 | 开关卡片，分组排列，修改记录时间线 |

### 4.3 响应式设计
- 桌面优先设计，最小宽度 1024px
- 平板适配：侧边栏可收起，表格横向滚动
- 移动端：候选人测评页优先适配，后台仅做基础可用

### 4.4 动效设计
- 页面切换：淡入淡出 200ms
- 卡片悬停：微上移 + 阴影加深
- 数据加载：骨架屏闪烁
- 预警出现：从右滑入 + 脉冲动画
- 开关切换：平滑滑动 150ms
