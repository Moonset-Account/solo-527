# 电动车充电桩故障可视化数据工作台 - PRD

## 1. 产品概述

电动车充电桩故障可视化数据工作台，基于多源数据（充电会话、功率、故障码、支付、站点巡检、维修工单）为运营团队提供可探索的故障分析平台。从"今天最异常的三件事"切入，支持多维度下钻分析，帮助快速定位故障根因、优化维修效率。

- 核心目标：降低故障平均修复时间（MTTR），提升充电桩可用率
- 目标用户：运营经理、运维工程师、数据分析人员

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 运营经理 | 关注整体运营指标和异常趋势 | 查看所有仪表盘、导出报告、筛选分析 |
| 运维工程师 | 负责具体故障处理和站点维护 | 查看故障详情、维修工单、站点信息 |
| 数据分析师 | 进行深度数据挖掘和归因分析 | 多维度下钻、自定义筛选、导出原始数据 |

### 2.2 功能模块

1. **总览仪表盘**：今日异常三件事、核心KPI、全局筛选器
2. **故障地图**：站点地理位置分布、故障热力、可用率展示
3. **功率分析**：功率曲线对比、异常功率标注、时段分布
4. **维修效率**：维修耗时分布、维修人排行、工单状态
5. **站点排行**：故障数、可用率、重复报修率综合排名
6. **报告中心**：CSV/PDF 报告导出、筛选条件持久化

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 总览仪表盘 | 今日异常三件事 | 智能识别当日最严重的3个异常，支持点击下钻 |
| 总览仪表盘 | 核心KPI卡片 | 显示可用率、故障数、平均修复时间、重复报修率，含样本量和更新时间 |
| 总览仪表盘 | 全局筛选器 | 支持站点、桩型、故障码、时段、维修人多维度联动筛选 |
| 故障地图 | 地图可视化 | 基于地理坐标展示站点，颜色映射故障严重程度，支持缩放平移 |
| 故障地图 | 站点详情弹窗 | 点击站点显示详细故障列表、功率趋势、可用率计算明细 |
| 功率分析 | 功率曲线图 | D3 绘制多桩功率曲线对比，支持异常区间高亮标注 |
| 功率分析 | 时段分布图 | 按小时/天展示故障发生时段分布规律 |
| 维修效率 | 维修耗时箱线图 | 按故障码/维修人展示耗时分布，识别异常慢工单 |

| 站点排行 | 排行榜表格 | 多指标综合排名，支持点击站点下钻到详情 |
| 报告中心 | 导出功能 | 支持当前筛选条件下的 CSV 原始数据和 PDF 可视化报告导出 |

## 3. 核心流程

用户从"今日最异常的三件事"入口进入，选择异常事件后自动联动筛选器，系统同步更新所有图表数据。用户可继续在各图表中进行交互筛选（点击地图站点、选择功率异常区间、筛选维修人等），所有图表保持联动。最后可导出包含当前筛选条件和所有图表的分析报告。

```mermaid
flowchart LR
    A["进入工作台"] --> B["查看今日异常三件事"]
    B --> C["点击异常事件自动筛选"]
    C --> D["联动更新所有图表"]
    D --> E["在各图表中交互下钻"]
    E --> F["查看站点/桩型/故障码详情"]
    F --> G["导出 CSV/PDF 报告"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主题色系**：深邃工业风，主色 #165DFF（科技蓝），辅助色 #FF4D4F（故障红）、#52C41A（正常绿）、#FAAD14（警告黄），深色背景 #0E1117
- **视觉风格**：数据仪表盘风格，卡片式布局，带微弱发光边框，科技感强
- **字体**：标题使用 Inter，数据展示使用 JetBrains Mono 等宽字体
- **动效**：数据加载骨架屏、图表渐入动画、筛选切换平滑过渡

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|-----------|-------------|-------------|
| 总览仪表盘 | 今日异常卡片 | 三列并排卡片，红黄绿警告色区分严重程度，悬停放大动效 |
| 总览仪表盘 | KPI 指标卡 | 左上角样本量标签，右下角更新时间，主数据大号字体 |
| 故障地图 | 地图容器 | 深色底图，站点圆点带发光效果，点击弹出详情面板 |
| 功率分析 | 曲线图 | D3 绘制，多色线条，异常区间用半透明红色蒙版标注 |
| 站点排行 | 排行表 | 斑马纹行，前三名带奖杯图标，可用率进度条可视化 |

### 4.3 响应式

- Desktop-first 设计，优先支持 1440px 及以上宽屏
- 图表容器使用 CSS Grid 自适应布局，小屏下自动堆叠
- 筛选栏在窄屏下折叠为抽屉式面板

### 4.4 特殊数据规则

- **可用率计算**：离线桩不纳入分母，公式 = 在线正常桩数 / (在线正常桩数 + 在线故障桩数)
- **重复报修合并**：同一桩体 ID、同一故障码、72小时内的报修单自动合并为一条，计数为1
- **样本量展示**：每张图表的左上角显示当前数据的样本量（N=xxx）
- **更新时间**：每张图表的右下角显示数据最后更新时间
