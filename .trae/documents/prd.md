## 1. 产品概述

试剂库存统计报表系统是一套面向实验室/科研机构的试剂全生命周期管理平台，解决试剂采购、领用、库存监控、经费管控与安全合规等核心问题。目标用户为试剂管理员、课题组负责人和系统管理员，通过数据驱动的统计报表直接服务采购决策与审计合规。

- 核心价值：将试剂从入库到领用的全流程数字化，实现库存实时可见、经费可控可追溯、合规审计有据可依
- 目标市场：高校实验室、科研院所、医药企业等需要严格试剂管理的组织

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 试剂管理员 | 管理员创建 | 试剂入库/出库、库存盘点、仪器停用提醒、经费管理、批量操作 |
| 课题组负责人 | 管理员创建 | 提交领用申请、查看课题报表、经费余额查询 |
| 系统管理员 | 系统初始化 | 权限审核、用户管理、系统配置、演示数据开关 |

### 2.2 功能模块

1. **库存统计报表页**：库存总览、分类统计、趋势图表、库存预警
2. **领用申请页**：提交领用申请、审批流程、领用记录
3. **课题报表页**：按课题维度的试剂消耗统计、经费使用报表
4. **安全合规页**：合规筛选、明细追溯、审计日志
5. **经费管理页**：经费余额、预算分配、支出统计
6. **权限审核页**：用户权限审核、角色分配、操作授权
7. **试剂批次页**：批量查看试剂批次、批次详情、有效期管理
8. **设备利用率看板页**：设备利用率图表、停用提醒同步、负责人确认
9. **操作历史页**：时间轴展示操作记录、交接备注、筛选与搜索

## 3. 核心流程

### 3.1 试剂领用流程
用户选择试剂并提交领用申请 → 系统校验库存与经费余额 → 管理员审批 → 审批通过后自动扣减库存与经费 → 生成领用记录与操作日志 → 更新课题报表

### 3.2 仪器停用提醒流程
系统检测到仪器异常或定期检定到期 → 向试剂管理员推送停用提醒 → 管理员确认停用原因 → 通知负责人确认 → 确认后同步到设备利用率看板 → 更新设备状态

### 3.3 安全合规追溯流程
管理员在合规页面设置筛选条件 → 系统按危险等级/管制类别过滤 → 点击统计数字下钻到明细 → 查看单笔出入库记录 → 导出合规报告

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝灰（#1E293B）+ 青绿强调色（#0D9488），体现专业严谨的实验室管理氛围
- 辅助色：琥珀色（#D97706）用于预警，红色（#DC2626）用于危险/超支提示
- 按钮风格：圆角（8px），主按钮实心填充，次按钮描边
- 字体：标题使用 DM Sans（粗体），正文使用 Noto Sans SC，数据使用 JetBrains Mono
- 布局风格：左侧导航 + 顶部面包屑 + 内容区卡片式布局
- 图标风格：Lucide 线性图标，与界面风格一致

### 4.3 响应式设计

- 桌面优先设计，最小支持 1280px 宽度
- 平板适配（768px-1279px）：导航折叠为汉堡菜单，卡片单列排列
- 移动端（<768px）：底部导航栏，卡片全宽，图表简化

### 4.4 生产环境要求

- 正式环境屏蔽所有演示样例数据，统计口径仅包含真实业务数据
- 演示数据通过环境变量 `DEMO_MODE` 控制，生产环境强制为 `false`
