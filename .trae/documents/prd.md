## 1. 产品概述

健身房私教课管理系统旨在帮助小型健身房将原本散落在 Excel、微信群中的私教课包、团课、会员冻结等业务统一管理，消除前台算错课时、漏续费、冻结期间误预约等痛点。目标用户为健身房前台、教练、管理员，核心价值是将"申请→审核→执行→复盘"的完整业务闭环数字化，并通过角色隔离和消息提醒确保关键节点不遗漏。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 管理员 | 系统预设 | 全模块读写、审核、教练业绩查看、续费漏斗、系统配置 |
| 教练 | 管理员创建 | 查看自己课表与学员、提交排班申请、查看本人业绩与收入、体测录入 |
| 前台 | 管理员创建 | 会员 CRUD、课包购买/续费、预约/签到、冻结/请假处理、消息通知 |
| 会员 | 前台创建 | 查看个人课包余额、预约记录、体测历史、到期提醒 |

### 2.2 功能模块

1. **登录页**：角色选择登录、JWT 鉴权
2. **工作台首页**：角色定制化仪表盘（管理员看全盘数据、教练看今日课程、前台看待办提醒）
3. **会员管理**：会员列表、详情、课包购买与续费、冻结/请假
4. **教练管理**：教练列表、排班日历、业绩面板（仅可见本人数据）
5. **课包管理**：课包定义（次数/有效期/价格）、购买记录、课时扣减流水
6. **团课管理**：团课排课、预约上限、签到扣减
7. **预约排班**：私教预约、团课预约、冲突检测、冻结拦截
8. **请假冻结**：会员请假申请→前台审核→自动冻结→到期恢复
9. **体测记录**：体测数据录入与历史曲线
10. **消息通知**：站内消息 + 邮件提醒（到期、续费、审核、排班变更）
11. **续费漏斗**：即将到期/已到期/续费转化率统计
12. **操作审计**：关键状态变更追溯日志

## 3. 核心流程

### 3.1 私教课预约流程

会员/前台发起预约 → 系统校验冻结状态 → 校验课包余额 → 校验教练时间冲突 → 预约成功 → 站内消息通知教练和会员 → 签到扣减课时 → 课时流水记录

### 3.2 会员请假冻结流程

会员/前台发起请假 → 前台审核 → 审核通过 → 课包有效期顺延 → 冻结期间不可预约 → 到期自动解冻 → 站内消息通知

### 3.3 续费漏斗流程

系统每日扫描即将到期课包 → T-7/T-3/T-1 天自动发送提醒 → 前台跟进标记 → 续费成功/流失标记 → 漏斗统计

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝灰(#1E293B) + 亮橙(#F97316)作为强调色，传达专业健身感
- 辅助色：翡翠绿(#10B981)用于成功/正常状态，玫红(#F43F5E)用于警告/过期
- 按钮：圆角8px、主按钮填充强调色、次按钮描边
- 字体：标题用 Noto Sans SC Bold，正文用 Noto Sans SC Regular
- 布局：左侧导航栏 + 右侧内容区，卡片式布局
- 图标：lucide-react 线性图标
- 整体风格：深色侧边栏 + 浅色内容区，现代管理后台风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 登录页 | 角色登录 | 居中卡片、角色图标选择、输入框、登录按钮、深色渐变背景 |
| 工作台首页 | 仪表盘 | 顶部统计卡片(4列)、中间图表区、底部待办列表 |
| 会员列表 | 会员管理 | 搜索栏+筛选标签、表格(头像/姓名/手机/状态/操作)、分页 |
| 会员详情 | 会员管理 | 左侧基本信息卡、右侧Tab切换(课包/预约/体测/冻结/日志) |
| 教练排班 | 教练管理 | 周日历视图、时间块可拖拽、颜色区分私教/团课/休息 |
| 预约页面 | 预约排班 | 左侧教练/团课选择、右侧日历选择时间、底部确认卡片 |
| 续费漏斗 | 续费漏斗 | 漏斗图+转化率、即将到期会员列表、快捷续费按钮 |
| 消息中心 | 消息通知 | 左侧消息分类、右侧消息列表、已读/未读标记 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度1280px
- 侧边栏在1024px以下折叠为图标模式
- 表格在小屏幕下横向滚动
- 卡片布局自适应列数
