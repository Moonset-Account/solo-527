## 1. 产品概述

铁路调度拼图是一款逻辑解谜游戏，玩家扮演铁路调度员，通过切换轨道岔口、设置信号灯和安排车次优先级，确保客运与货运列车准点安全通过。目标用户为喜欢逻辑推理和解谜的休闲玩家，单局体验在十分钟内完成完整循环。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 说明 |
|------|------|
| 调度员（玩家） | 控制轨道切换、信号灯、车次优先级 |

### 2.2 功能模块
1. **开始菜单**：新游戏、继续游戏、教程入口
2. **教程关卡**：交互式引导，教会玩家基础操作
3. **游戏主场景**：轨道网络、列车运行、信号灯控制、车次表
4. **结算界面**：通过/失败结果、冲突原因展示、评分、重试

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 开始菜单 | 标题与按钮 | 显示游戏标题，提供"新游戏"、"继续"、"教程"按钮 |
| 开始菜单 | 关卡选择 | 显示已解锁关卡列表及星级评价 |
| 教程场景 | 引导步骤 | 分步高亮操作区域，箭头提示点击位置 |
| 游戏场景 | 轨道网络 | 可视化轨道节点、岔口、站台，可点击切换 |
| 游戏场景 | 信号灯 | 红/绿灯控制，点击切换状态 |
| 游戏场景 | 车次表 | 显示当前关卡所有列车类型、时刻、状态 |
| 游戏场景 | 冲突提示 | 实时检测并显示冲突原因（同轨碰撞、晚点连锁、站台占用） |
| 游戏场景 | 时间轴 | 显示游戏时间进度，列车到站/发车倒计时 |
| 游戏场景 | 回放控制 | 可回退到上一步、重置关卡 |
| 结算界面 | 结果展示 | 通过/失败动画、星级评分、用时统计 |
| 结算界面 | 冲突日志 | 列出所有冲突事件及原因 |
| 结算界面 | 操作按钮 | 重试本关、下一关、返回菜单 |

## 3. 核心流程

玩家从开始菜单进入，选择关卡或教程。游戏中观察轨道布局和车次表，在列车到达前切换岔口方向和信号灯，为高优先级列车让路。若发生冲突（同轨碰撞、晚点连锁、站台占用），系统实时提示冲突原因。所有列车准点通过则通关，否则可重试。通关后展示结算界面，记录评分。

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深铁蓝（#1a2744）为底，信号红（#e63946）和信号绿（#2a9d8f）为功能色，轨道灰（#6c757d）为中性色
- **按钮风格**：圆角矩形，3D 凸起效果，hover 时发光
- **字体**：标题使用等宽粗体风格（仿铁路时刻表），正文使用清晰无衬线体
- **布局**：上方车次表 + 时间轴，中央轨道鸟瞰图，下方操作提示
- **图标**：铁路信号灯、岔口、列车轮廓等简笔图标

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 开始菜单 | 标题区 | 大号等宽标题、铁轨装饰线、蒸汽动画背景 |
| 开始菜单 | 按钮区 | 3D圆角按钮、hover发光、点击缩放 |
| 教程场景 | 高亮区 | 半透明遮罩、箭头动画、脉冲边框 |
| 游戏场景 | 轨道区 | 俯视轨道网络、岔口节点高亮、信号灯动画 |
| 游戏场景 | 信息栏 | 车次表卡片、时间轴滑块、状态标签 |
| 游戏场景 | 冲突弹窗 | 红色边框弹窗、冲突原因文字、闪烁警告 |
| 结算界面 | 评分区 | 星星动画、数字翻滚、彩色进度条 |
| 结算界面 | 日志区 | 滚动列表、颜色标记（红/绿/灰） |

### 4.3 响应式设计
- 以桌面端（1280×720）为主要目标
- 最小支持 960×540 分辨率
- 触屏设备支持点击操作

### 4.4 动画与反馈
- 列车运行：沿轨道平滑移动，带尾焰效果
- 岔口切换：轨道旋转动画 + 机械咔嗒音效
- 信号灯切换：红绿灯切换动画 + 叮咚音效
- 冲突发生：屏幕震动 + 警报音效 + 红色闪烁
- 通关：烟花粒子 + 欢快音效
- 失败：画面变灰 + 低沉音效
