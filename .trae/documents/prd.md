# 联合办公房源租约账单系统 - 产品需求文档

## 1. 项目概述

### 1.1 项目背景
联合办公空间运营需要高效管理房源租约与账单流程，涉及多角色协作、复杂计费规则和争议处理机制。本系统旨在通过数字化手段提升租约账单管理效率，降低人工操作风险。

### 1.2 项目目标
- 实现租约与账单的全生命周期管理
- 支持多角色权限控制与协作流程
- 提供可配置的字段字典和校验规则
- 支持收租进度跟踪与明细导出
- 建立押金争议异常处理机制
- 完整记录操作留痕与审计追踪

### 1.3 目标用户
- **财务专员**: 查询租约账单、顾问跟进、业主结算
- **顾问**: 跟进租约进展、处理租客咨询
- **租客客服**: 处理押金争议、办结异常单并留下处理说明
- **管理员**: 系统配置、人员管理、全量数据查询

---

## 2. 功能需求

### 2.1 账号与角色管理
- 支持多角色账号体系（管理员、财务专员、顾问、租客客服）
- 基于角色的权限控制（RBAC）
- 账号状态管理（启用/禁用）
- 操作日志记录所有修改人和修改时间

### 2.2 租约管理
- 租约信息录入与编辑
- 租约列表查询（按日期、状态、人员筛选）
- 租约详情查看
- 租约状态流转（待生效、生效中、已到期、已终止）
- 关联房源、租客、业主信息

### 2.3 账单管理
- 租金账单自动/手动生成
- 押金账单管理
- 账单状态跟踪（待支付、已支付、逾期、已作废）
- 收租进度明细查询与下载
- 批量账单生成（后台管理功能）

### 2.4 异常单管理
- 押金争议触发异常单生成
- 异常单状态流转（待处理、处理中、已办结）
- 租客客服办结时填写处理说明
- 异常单关联对应租约和账单

### 2.5 字段字典配置
- 可配置的业务字典（租约类型、账单类型、状态枚举等）
- 字典项的增删改查
- 字典版本管理
- 修改记录留痕

### 2.6 校验规则配置
- 可配置的数据校验规则
- 支持金额范围、日期范围、正则表达式等校验方式
- 规则启用/禁用管理
- 校验结果提示

### 2.7 数据查询与导出
- 多维度组合查询（日期、状态、人员）
- 收租进度明细报表
- 支持 Excel/CSV 格式导出
- 列表分页与排序

### 2.8 操作留痕
- 所有重要数据修改记录修改人、修改时间
- 修改前后数据对比
- 操作日志查询

## 3. 用户角色与权限

### 3.1 管理员
- 全部功能权限
- 用户账号与角色管理
- 字段字典配置
- 校验规则配置
- 全量数据查询与导出
- 操作日志查看

### 3.2 财务专员
- 租约账单查询
- 收租进度查看
- 顾问跟进记录
- 业主结算管理
- 账单数据导出

### 3.3 顾问
- 负责租约的查询与跟进
- 租客信息查看
- 跟进记录添加
- 个人负责数据导出

### 3.4 租客客服
- 异常单处理
- 押金争议处理
- 办结处理说明填写
- 关联租约和账单查看

---

## 4. 业务流程

### 4.1 租约账单生成流程
```
租约生效 → 定时任务触发 → 生成租金账单 → 通知财务专员 → 确认收款 → 账单完成
```

### 4.2 押金争议处理流程
```
发现押金争议 → 生成异常单 → 分配给客服 → 客服处理 → 填写处理说明 → 办结
```

### 4.3 收租进度跟踪流程
```
账单生成 → 待支付 → 催收 → 部分支付 → 全额支付 → 账单结清
```

---

## 5. 非功能需求

### 5.1 性能要求
- 列表查询响应时间 < 2 秒
- 账单批量生成支持 1000+ 条异步处理
- 导出功能支持万级数据量

### 5.2 安全要求
- 用户密码加密存储
- API 接口鉴权
- 敏感数据脱敏显示
- SQL 注入防护

### 5.3 可用性要求
- 系统可用率 99.5%
- 数据每日备份
- 异常单处理超时提醒

---

## 6. 数据实体概览

- 用户（User）
- 角色（Role）
- 权限（Permission）
- 房源（Property）
- 租客（Tenant）
- 业主（Owner）
- 租约（Lease）
- 账单（Bill）
- 异常单（ExceptionOrder）
- 字段字典（Dictionary）
- 校验规则（ValidationRule）
- 操作日志（OperationLog）
- 跟进记录（FollowUpRecord）
