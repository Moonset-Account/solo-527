## 1. 产品概述
洗车门店经营看板——为洗车门店提供从预约、收银到运营分析的一体化管理工具。面向店长和运营人员，解决预约排期混乱、收入客流数据割裂、到店转化率低且缺乏预警、待办处理信息分散等核心问题，帮助门店提升运营效率和客户转化。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 店长 | 管理员分配账号 | 管理预约服务、查看支付、处理待办、查看经营看板 |
| 运营人员 | 管理员分配账号 | 查看门店收入统计、客流统计、到店转化预警、配件周转报表 |

### 2.2 功能模块
1. **经营看板页**：今日概览（预约数/收入/客流/转化率）、到店转化预警卡片、待办快速入口
2. **预约管理页**：预约列表与筛选、预约创建/编辑、支付关联、状态流转
3. **支付管理页**：收银单列表、支付状态跟踪、收入统计
4. **待办处理页**：待办列表（按状态/日期/负责人过滤）、处理视图（时间轴）、关联检测模板/收银单/车辆档案
5. **运营统计页**：门店收入图表、客流趋势图、到店转化率与预警线、配件周转报表

## 3. 核心流程

**预约→服务→支付→统计** 主流程：
1. 客户发起预约（洗车/保养/试驾），系统创建预约记录并关联车辆档案
2. 到店后店长确认服务，系统自动检测车辆是否有待办事项
3. 服务完成后生成收银单，关联检测模板结果
4. 支付完成后数据同步到运营统计面板
5. 到店转化率低于阈值时触发预警
6. 试驾改期时，处理节点自动同步到配件周转报表

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深海蓝 (#0F172A) + 亮蓝 (#3B82F6) 作为强调色
- 辅助色：翠绿 (#10B981) 表示完成/正常，琥珀 (#F59E0B) 表示预警，玫红 (#EF4444) 表示紧急
- 按钮风格：圆角 8px，轻微阴影，hover 状态加深
- 字体：思源黑体/Noto Sans SC，标题 20-24px，正文 14px，辅助文字 12px
- 布局风格：左侧导航 + 右侧内容区，卡片式布局，顶部指标卡片横排
- 图标风格：线性图标（Lucide），与文字搭配使用

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 经营看板 | 今日概览 | 四个指标卡片横排，数字大字+趋势箭头，卡片圆角阴影 |
| 经营看板 | 到店转化预警 | 预警卡片，红/黄/绿状态色条，预警原因文字 |
| 经营看板 | 待办快速入口 | 紧急度色标的列表项，点击跳转处理视图 |
| 预约管理 | 预约列表 | 表格+顶部筛选栏，状态标签颜色区分 |
| 预约管理 | 预约详情 | 右侧抽屉，包含车辆信息+服务项目+支付状态 |
| 支付管理 | 收银单列表 | 表格+筛选，支付状态标签 |
| 待办处理 | 待办列表 | 左侧列表+右侧处理视图，筛选栏在顶部 |
| 待办处理 | 处理视图 | 时间轴布局，关联资源以卡片形式嵌入时间节点 |
| 运营统计 | 收入统计 | 折线图+柱状图组合，时间范围选择器 |
| 运营统计 | 到店转化预警 | 折线图+预警线(虚线)，预警区域高亮 |

### 4.3 响应式
- 桌面优先设计，1280px 以上完整布局
- 平板（768-1280px）侧边栏收起为图标模式
- 手机（<768px）单列布局，卡片堆叠

不适用
