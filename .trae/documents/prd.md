## 1. 产品概述

租赁公寓维修响应看板系统，面向资产运营团队，提供供应商绩效监控与分析能力。通过复修率、响应超时榜、租户低分反馈三大核心入口，结合地图可视化与多维度下钻分析，帮助运营团队快速识别问题供应商，优化维修服务质量。

### 核心价值
- 实时监控供应商响应时效与服务质量
- 多维度下钻分析，定位问题根因
- 复修工单关联追溯，避免重复计费
- 节假日智能标记，客观评估供应商表现

## 2. 核心功能

### 2.1 用户角色

| 角色 | 核心权限 |
|------|----------|
| 资产运营经理 | 查看看板、筛选下钻分析、导出数据、查看工单详情 |
| 供应商管理员 | 查看绩效数据、申诉工单、查看材料照片 |

### 2.2 功能模块

1. **核心看板页**：复修率概览、响应超时榜、租户低分反馈、地图可视化
2. **工单列表页**：多维度筛选、工单状态跟踪、复修关联展示
3. **供应商详情页**：供应商绩效详情、历史趋势、申诉处理
4. **工单详情页**：生命周期、材料消耗、租户评价、申诉记录

| 页面名称 | 模块名称 | 功能描述 |

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深海军蓝 (#0F2B4A) 作为主色，体现专业与信任感
- **辅助色**：警示红 (#E63946)、成功绿 (#2A9D8F)、警告橙 (#F4A261)
- **中性色**：石板灰渐变背景，白色卡片，深灰文字
- **字体**：展示字体使用 Cormorant Garamond（标题），正文字体使用 Inter（数据展示）
- **卡片风格**：圆角 16px，微妙投影，hover 时轻微上浮
- **布局**：侧边导航 + 主内容区，卡片式网格布局
- **图标风格**：线性图标，统一 24px 网格

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|-----------|-------------|-------------|
| 核心看板 | 顶部指标卡 | 渐变背景、大号数字、趋势箭头、迷你图表 |
| 核心看板 | 地图区域 | 全屏暗色地图、聚合气泡、hover 弹窗 |
| 核心看板 | 排行榜 | 排名序号、进度条、状态标签 |
| 工单列表 | 筛选栏 | 下拉选择器、日期范围、搜索框 |
| 工单列表 | 数据表格 | 斑马纹、状态徽章、悬停高亮 |
| 工单详情 | 时间轴 | 垂直时间线、节点标记、状态颜色 |

### 4.3 响应式

- Desktop-first 设计，适配 1440px 为主
- 平板端调整卡片堆叠，地图自适应
- 移动端简化导航，表格横向滚动

### 4.4 动效设计

- 页面加载：卡片错落淡入，延迟递增
- 数据更新：数字滚动动画
- 悬停效果：卡片轻微上浮 + 阴影加深
- 地图交互：点位缩放平滑过渡
