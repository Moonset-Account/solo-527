## 二、指标口径验收

### 2.1 库存类指标
- [ ] 期初库存：取值正确，与业务系统一致
- [ ] 期末库存：取值正确，与业务系统一致
- [ ] 入库数量：按类型统计正确
- [ ] 出库数量：按类型统计正确
- [ ] 库存金额：成本计算正确
- [ ] 库存周转天数：公式验证通过
- [ ] 库存周转率：公式验证通过

### 2.2 库龄类指标
- [ ] 库龄天数：生产日期/入库日期取值正确
- [ ] 库龄分布：5个区间划分正确
- [ ] 平均库龄：数量加权正确

### 2.3 效期类指标
- [ ] 距到期天数：计算正确
- [ ] 近效期判定：<=30天 判定正确
- [ ] 临期判定：<=7天 判定正确

### 2.4 滞销类指标
- [ ] 滞销SKU：库龄>180天 且 近30天无出库
- [ ] 慢销SKU：库龄>90天 且 近30天出库<库存10%

### 2.5 补货类指标
- [ ] 可供应天数：当前库存/日均需求 正确
- [ ] 缺货判定：库存 < min_stock_qty
- [ ] 建议补货量：公式验证通过
- [ ] 超储判定：库存 > max_stock_qty

## 三、数据质量验收

### 3.1 缺失值检查
- [ ] 关键字段缺失率 < 1%：sku_id, batch_no, snapshot_date, qty
- [ ] 无完全空行

### 3.2 异常点检查
- [ ] 无负库存（closing_qty < 0）
- [ ] 库存平衡：期初 + 入库 - 出库 + 净退货 = 期末
- [ ] 无重复批次（同SKU+仓库+库位+批次 唯一）
- [ ] 周转天数在合理范围（0-365天）

### 3.3 样本量检查
- [ ] 库存明细表：>= 100条
- [ ] 入库明细表：>= 50条
- [ ] 出库明细表：>= 50条
- [ ] 退货明细表：>= 10条
- [ ] SKU主档：>= 10个
- [ ] 供应商：>= 3个
- [ ] 仓库/库位：>= 5个

### 3.4 一致性检查
- [ ] 数据延迟 <= 2天
- [ ] SKU编码在各表中一致
- [ ] 仓库编码在各表中一致
- [ ] 批次号在入库/库存/出库中可关联
