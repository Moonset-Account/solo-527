# 仓库SKU周转与滞销分析 - 指标口径定义

## 一、库存类指标

### 1.1 期初库存
- **定义**：统计周期开始时的库存数量
- **计算公式**：`sum(opening_qty)`
- **粒度**：日/周/月，按SKU+仓库+批次
- **数据源**：`ods_inventory_detail.opening_qty`
- **说明**：取每日快照表中当日期初值

### 1.2 期末库存
- **定义**：统计周期结束时的库存数量
- **计算公式**：`sum(closing_qty)`
- **粒度**：日/周/月，按SKU+仓库+批次
- **数据源**：`ods_inventory_detail.closing_qty`
- **说明**：取周期最后一天的期末值

### 1.3 入库数量
- **定义**：统计周期内累计入库数量
- **计算公式**：`sum(inbound_qty)` 或 `sum(actual_qty)` from 入库单
- **粒度**：日/周/月，按SKU+仓库+批次+供应商
- **数据源**：`ods_inventory_detail.inbound_qty` / `ods_inbound_detail.actual_qty`
- **入库类型细分**：
  - 采购入库
  - 退货入库
  - 调拨入库
  - 生产入库

### 1.4 出库数量
- **定义**：统计周期内累计出库数量
- **计算公式**：`sum(outbound_qty)` 或 `sum(actual_qty)` from 出库单
- **粒度**：日/周/月，按SKU+仓库+批次
- **数据源**：`ods_inventory_detail.outbound_qty` / `ods_outbound_detail.actual_qty`
- **出库类型细分**：
  - 销售出库
  - 调拨出库
  - 报损出库
  - 领用出库

### 1.5 库存金额
- **定义**：期末库存的成本金额
- **计算公式**：`sum(closing_qty * unit_cost)`
- **粒度**：日/周/月，按SKU+仓库
- **数据源**：`ods_inventory_detail.closing_amount`

### 1.6 库存周转天数
- **定义**：库存从入库到出库平均需要的天数
- **计算公式**：`(周期日均库存 / 周期总出库量) * 周期天数`
- **粒度**：周/月/季度/年，按SKU+仓库+分类
- **计算逻辑**：
  ```
  月周转天数 = (月日均库存 / 月总出库量) * 30
  其中：月日均库存 = 每日期末库存之和 / 当月天数
  ```
- **数据源**：`dws_sku_turnover_monthly`
- **等级划分**：
  - A级：≤7天（极快）
  - B级：8-15天（较快）
  - C级：16-30天（正常）
  - D级：31-60天（较慢）
  - E级：61-90天（慢）
  - F级：>90天（滞销）

### 1.7 库存周转率
- **定义**：统计周期内库存周转的次数
- **计算公式**：`周期总出库量 / 周期平均库存量`
- **粒度**：月/季度/年，按SKU+仓库+分类
- **数据源**：`dws_sku_turnover_monthly`

## 二、库龄类指标

### 2.1 库龄天数
- **定义**：批次从入库到统计日的天数
- **计算公式**：`统计日期 - 生产日期` 或 `统计日期 - 入库日期`
- **粒度**：批次级
- **数据源**：`ods_inventory_detail.inventory_age_days`
- **说明**：优先使用生产日期，无生产日期时使用最早入库日期

### 2.2 库龄分布
- **定义**：按库龄区间统计的库存数量/金额占比
- **区间划分**：
  - 0-7天：新鲜库存
  - 8-30天：正常库存
  - 31-90天：关注库存
  - 91-180天：预警库存
  - 180天+：滞销库存
- **计算公式**：各区间库存 / 总库存 * 100%
- **数据源**：`ads_inventory_age_distribution`

### 2.3 平均库龄
- **定义**：按数量加权的平均库龄
- **计算公式**：`sum(closing_qty * inventory_age_days) / sum(closing_qty)`
- **粒度**：SKU/分类/仓库
- **数据源**：`dws_sku_inventory_daily`

---

## 三、效期类指标

### 3.1 距到期天数
- **定义**：批次有效期截止日距离统计日的天数
- **计算公式**：`expiry_date - snapshot_date`
- **粒度**：批次级
- **数据源**：`ods_inventory_detail.days_to_expiry`

### 3.2 近效期占比
- **定义**：距到期≤30天的库存占总库存的比例
- **计算公式**：`近效期库存数量 / 总库存数量 * 100%`
- **告警阈值**：
  - 红色告警：≤7天（临期）
  - 橙色告警：8-30天（近效期）
  - 黄色提醒：31-90天（关注）
- **数据源**：`ads_inventory_alerts`

### 3.3 过期库存金额
- **定义**：已过有效期的库存成本金额
- **计算公式**：`sum(if(days_to_expiry <= 0, closing_amount, 0))`
- **数据源**：`ods_inventory_detail`

---

## 四、滞销类指标

### 4.1 滞销SKU数量
- **定义**：满足以下任一条件的SKU数量
  1. 库龄 > 180天 且 近30天无出库
  2. 库龄 > 90天 且 近30天出库 < 库存量的10%
- **数据源**：`ads_inventory_alerts`

### 4.2 滞销库存金额占比
- **定义**：滞销库存金额 / 总库存金额 * 100%
- **告警阈值**：>10% 需要关注

### 4.3 滞销降级率
- **定义**：本期从正常转为滞销的SKU数 / 上期正常SKU数

---

## 五、补货类指标

### 5.1 可供应天数
- **定义**：按当前出库速度，现有库存可供应的天数
- **计算公式**：`当前库存 / 近30天日均出库量`
- **数据源**：`ads_replenishment_suggestion.days_of_supply`

### 5.2 缺货SKU数量
- **定义**：当前库存 < 安全库存的SKU数量
- **细分**：
  - 严重缺货：库存 < min_stock_qty
  - 建议补货：min_stock_qty ≤ 库存 < reorder_point
- **数据源**：`ads_replenishment_suggestion`

### 5.3 建议补货量
- **定义**：建议的补货数量
- **计算公式**：
  ```
  建议补货量 = max(
      reorder_qty,  -- 配置的再订货量
      ceil(日均需求 * 提前期 * 1.5)  -- 基于需求的计算
  )
  ```
- **数据源**：`ads_replenishment_suggestion`

### 5.4 超储SKU数量
- **定义**：当前库存 > max_stock_qty 的SKU数量
- **超储率**：`(实际库存 - max_stock_qty) / max_stock_qty * 100%`

---

## 六、退货类指标

### 6.1 退货率
- **定义**：退货数量 / 出库数量 * 100%
- **粒度**：SKU/供应商/仓库
- **时间范围**：近30天/近90天

### 6.2 退货原因分布
- **定义**：按退货原因统计的退货数量/金额占比
- **常见原因**：质量问题、发错货、临期、客户取消等

### 6.3 不可二次销售退货占比
- **定义**：不可二次销售退货数量 / 总退货数量 * 100%

---

## 七、供应商相关指标

### 7.1 供应商准时交货率
- **定义**：准时入库单数量 / 总入库单数量 * 100%

### 7.2 供应商品质合格率
- **定义**：(总入库量 - 退货量- 报损量) / 总入库量 * 100%

### 7.3 供应商供货占比
- **定义**：某供应商供货量 / 该SKU总供货量 * 100%

---

## 八、异常判定规则

| 异常类型 | 判定规则 | 严重等级 |
|---------|---------|---------|
| 临期商品 | 距到期 ≤ 7天 且 库存 > 0 | 高 |
| 近效期 | 距到期 ≤ 30天 且 库存 > 0 | 中 |
| 滞销商品 | 库龄 > 180天 且 近30天无出库 | 高 |
| 慢销商品 | 库龄 > 90天 且 近30天出库 < 库存10% | 中 |
| 严重缺货 | 库存 < min_stock_qty | 高 |
| 建议补货 | 库存 < reorder_point | 中 |
| 超储 | 库存 > max_stock_qty | 中 |
| 周转异常 | 周转天数 > 90天 | 中 |
| 负库存 | 期末库存 < 0 | 高 |
| 退货率过高 | 退货率 > 10% | 中 |

## 九、数据刷新频率

| 数据层 | 刷新频率 | 延迟 | 说明 |
|-------|---------|------|------|
| ODS层入库/出库/退货 | 实时（CDC） | < 1分钟 | 基于Debezium CDC同步 |
| ODS层库存快照 | 每日凌晨2点 | T+1 | 日结任务生成 |
| DWS层聚合表 | 每日凌晨3点 | T+1 | 物化视图刷新 |
| ADS层应用视图 | 实时 | 实时 | 基于ODS+DWS实时计算 |
| 补货建议 | 每6小时 | < 6小时 | 定时刷新 |
| 预警通知 | 每小时 | < 1小时 | 近效期/缺货预警 |
