# 健身房会员训练留存分析 - 指标口径定义

## 一、基础维度定义

### 1.1 会员维度
- **会员类型**: 按会员卡类型划分（月卡/季卡/年卡/私教课等）
- **入会月份**: 会员首次缴费的自然月份
- **门店**: 会员注册所属门店
- **年龄分层**: 18-25岁、26-35岁、36-45岁、46岁以上
- **性别**: 男/女

### 1.2 时间维度
- **自然月**: 日历月
- **入会周/月**: 以入会日期为第0周/月计算的相对时间
- **停卡排除**: 计算活跃天数和留存时，需扣除会员停卡期间

## 二、核心指标口径

### 2.1 留存类指标

#### 留存率 (Retention Rate)
**定义**: 某一批次（Cohort）的会员，在后续第N个月仍有签到记录的比例
**公式**: 
```
第N月留存率 = (入会第N个月有签到的会员数 - 停卡会员数) / (当期活跃会员总数 - 停卡会员数)
```
**注意事项**:
- 停卡期间的会员不计入流失样本
- 样本量<30时需标注"样本量不足"
- 签到记录需排除异常测试数据

#### 7日/30日复训率
**定义**: 单次训练后，7天/30天内再次训练的会员比例
**公式**:
```
7日复训率 = 训练后7天内再次签到的会员数 / 总训练会员数
```

### 2.2 活跃度类指标

#### 月均训练频次
**定义**: 活跃会员每月平均训练次数
**公式**:
```
月均训练频次 = 月总签到次数 / (月活跃会员数 - 月均停卡会员数)
```

#### 会员生命周期 (Lifecycle)
**定义**: 从入会到最近一次签到的天数（排除停卡期）
**公式**:
```
有效生命周期 = 最近签到日期 - 入会日期 - 累计停卡天数
```

### 2.3 流失类指标

#### 流失定义
- **自然流失**: 连续30天无签到记录且非停卡状态
- **预警流失**: 连续14天无签到记录且非停卡状态
- **高风险流失**: 历史周均训练≥2次，最近7天无训练

#### 流失率
**公式**:
```
月流失率 = 本月新增流失会员数 / (月初活跃会员数 + 本月新入会会员数)
```
**注意**: 分子分母均需扣除停卡会员

### 2.4 课程类指标

#### 课程热度
- **预约率**: 预约人数 / 课程容量
- **签到率**: 实际签到人数 / 预约人数
- **取消率**: 取消预约人数 / 总预约人数

#### 人均课程消费
**公式**: 课程总收入 / 上课会员数

### 2.5 教练类指标

#### 教练负载
- **周均课时数**: 教练每周实际授课时长
- **学员数**: 教练当前服务的活跃会员数
- **私教转化率**: 购买私教课的会员数 / 接触过的会员数

#### 教练留存影响
- 带教学员的月留存率
- 学员续费率

### 2.6 私教类指标

#### 私教购买转化率
**公式**: 购买私教课的会员数 / 体测会员数

#### 私教课消课率
**公式**: 已消课时数 / 已购课时总数

## 三、异常检测规则

### 3.1 数据异常
- 单日签到量波动>±50%（环比上周同日）
- 单门店流失率>20%
- 课程取消率>40%
- 会员反馈平均评分<3分

### 3.2 样本量预警
- Cohort组样本量<30人
- 单维度筛选后样本量<50人
- 新增指标展示时自动检测样本量

## 四、数据清洗规则

### 4.1 数据排除
- 测试会员账号（手机号含TEST或标记为测试）
- 员工训练记录
- 重复签到（同一会员1小时内多次签到仅计1次）
- 异常值（训练时长>6小时或<5分钟）

### 4.2 缺失值处理
- 会员年龄缺失用同类型会员中位数填充
- 体测数据缺失不参与体测相关指标计算
- 停卡原因缺失统一标记为"未说明"
