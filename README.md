# 🤖 仓库潜行机器人 (Stealth Warehouse Bot)

一款小而完整的仓库潜行解谜游戏 Demo。控制维护机器人潜入仓库，避开巡逻灯，扫描货架并修复错误标签。

---

## 🎮 核心玩法

### 游戏目标
- **扫描货架**：使用扫描仪读取货架标签
- **修复标签**：发现错误标签后进行修复
- **避开巡逻**：不被巡逻灯的视野锥发现
- **到达出口**：完成目标后抵达出口区域

### 特色系统

| 系统 | 说明 |
|------|------|
| 👁 **视野锥** | 巡逻灯有扇形视野锥，颜色变化代表状态：黄色=巡逻 / 橙色=调查 / 红色=警报 |
| 📡 **噪音系统** | 移动产生噪音，过大噪音会吸引巡逻灯前来调查 |
| 🔋 **能量系统** | 扫描和冲刺消耗能量，蹲伏不动恢复能量 |
| 🚩 **检查点** | 被发现只回退到最近检查点，无需重玩整关 |
| ⭐ **评价系统** | 根据用时、被发现次数、剩余能量评定1~3星 |

### 操作指南

```
WASD / 方向键    移动机器人
空格键(长按)    扫描附近货架
E键             修复错误标签（需先扫描发现）
Shift键         冲刺（高耗能·高噪音）
Ctrl键          蹲伏（恢复能量·低噪音）
ESC键           暂停游戏
F1键            显示/隐藏调试日志
```

## 🗺️ 关卡设计

### 关卡1 - 新手仓库 ⭐
- **难度**：简单
- **目标**：扫描 3 个货架，修复 1 个标签
- **特点**：单盏巡逻灯，开阔区域，用于熟悉操作

### 关卡2 - B区货仓 ⭐⭐
- **难度**：普通
- **目标**：扫描 5 个货架，修复 2 个标签
- **特点**：两盏巡逻灯，多段巡逻路线，需合理利用检查点

### 关卡3 - 核心物流区 ⭐⭐⭐
- **难度**：困难
- **目标**：扫描 7 个货架，修复 3 个标签
- **特点**：三盏巡逻灯，密集路线，墙体遮挡多，需规划路线

## 🚀 运行方法

### 方式1：Godot编辑器
1. 安装 Godot 4.2+ (推荐4.6.3)
2. 启动 Godot，点击 **导入(Import)**
3. 选择本项目目录下的 `project.godot`
4. 点击 **播放(F5)** 按钮启动

### 方式2：命令行运行
```bash
# 语法检查
godot --headless --check-only --path .

# 直接运行
godot --path .

# 导出(需配置导出模板)
godot --export "Windows Desktop" game.exe
godot --export "macOS" game.zip
godot --export "Linux/X11" game.x86_64
```

## 🎯 主循环验证清单

- ✅ 开始菜单 → 关卡1 → 扫描货架 → 修复标签 → 出口 → 结算
- ✅ 关卡选择 → 选择已解锁关卡 → 正常游戏
- ✅ 暂停(ESC) → 继续/重玩/返回菜单
- ✅ 被巡逻灯发现 → 回退到最近检查点 → 继续游戏
- ✅ 结算面板 → 下一关/重玩/关卡选择/回主菜单
- ✅ 设置 → 修改音量 → 保存 → 重启仍生效
- ✅ 完成关卡 → 成就自动解锁 → 弹窗提示
- ✅ 每日挑战 → 记录最佳分 → 次日自动重置
- ✅ 调试日志(F1) → 实时查看所有系统事件

## 📌 设计亮点

1. **渐进式难度**：第1关不堆难度，帮助玩家熟悉操作
2. **小段重置机制**：被发现只回退到最近检查点，玩家体验友好
3. **多维度反馈**：颜色·进度条·弹窗·调试日志四层反馈
4. **程序化构建**：所有UI和关卡用代码生成，资源依赖少
5. **完整留存系统**：存档·成就·排行榜·每日挑战四层驱动力
6. **可扩展架构**：新增关卡只需在LevelConfig中添加配置数据
