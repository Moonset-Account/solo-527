# 古诗词词牌拼接游戏

一个基于 Vue 3 + Canvas 开发的古诗词益智游戏，让玩家在拼接诗句的过程中学习平仄韵律和诗词知识。

## ✨ 核心特性

### 🎮 核心玩法
- **填字模式**：根据平仄、意象和提示填入缺失的字
- **排序模式**：将打乱的字重新排列成正确诗句
- **选择模式**：从多个选项中选择最合适的字
- **混合模式**：结合多种玩法的复合关卡

### 📚 学习功能
- **平仄系统**：每个字标注平/仄声，格律诗下方附带格律参考
- **错误详解**：答错时解释平仄原因、正确答案及格律依据
- **学习卡片**：通关解锁诗词知识卡片（词牌知识、诗人介绍、格律要点等）

### 🏆 评分系统
- **基础分数**：按难度计算正确答案得分
- **连击加成**：连续答对获得额外分数倍率
- **平仄奖励**：平仄匹配额外加分
- **时间奖励**：剩余时间换算为额外分数
- **星级评价**：根据得分获得 1-3 星
- **等级评级**：S/A/B/C/D 五级评价（诗仙/诗圣/诗人/学子/初学）

### 💾 存档系统
- localStorage 持久化存储
- 关卡进度、分数、星级记录
- 学习卡片解锁状态
- 游戏设置（音量、难度、提示开关）
- 数据统计（游戏次数、解题数、提示使用、完美通关数）

### 🔊 音频系统
- Web Audio API 合成音效（无需外部资源）
- 按钮、拾取、放置、正确、错误、场景切换、通关、提示等音效
- 程序化合成背景音乐（和平/激昂/胜利三种风格）
- 独立音量调节和静音开关

### 🎨 视觉反馈
- 场景切换淡入淡出过渡
- 正确答案绿色闪光动画
- 答错屏幕震动反馈
- 按钮悬停发光效果
- 字符缩放与脉冲动画
- 渐变填充、金色文字阴影
- 程序化生成装饰资源（竹、山、花、卷轴、人物、金币等）

## 📁 项目结构

```
src/
├── App.vue                          # 主应用组件

├── components/

│   └── levels.js                    # 关卡配置（6关 + 词牌说明）
└── scenes/
    ├── BaseScene.js                 # 场景基类（UI/按钮/渲染工具）
    ├── MenuScene.js                 # 主菜单场景
    ├── LevelSelectScene.js          # 关卡选择场景
    ├── GameScene.js                 # 游戏核心场景（玩法/胜负/结算）
    ├── LearningScene.js             # 学习卡片场景
    └── SettingsScene.js             # 设置场景
```

## 🎯 模块说明

### SceneManager 场景管理
- 负责场景注册、切换和生命周期管理
- 内置淡入淡出过渡动画
- 粒子系统支持（爆裂、飘动效果）

### InputMapper 输入映射
- 统一处理 Canvas 坐标换算（考虑 CSS 缩放）
- 支持鼠标、触摸、键盘事件
- 事件订阅/发布模式

### AudioManager 音频管理
- 使用 Web Audio API 合成所有音效
- 不依赖任何外部音频文件，完全程序化
- 独立的 SFX/BGM 音量控制
- BGM 采用循环音符生成算法

### PuzzleSystem 拼图系统
- ScoringSystem：多维评分算法
- PuzzleValidator：答案验证与错误解释生成
- 平仄模式检查与违规位置定位

### GameLoop 游戏主循环
- 固定时间步长更新（60fps）
- 最大 Delta 限制避免跳帧
- FPS 统计支持

## 🎓 教育目标

本游戏专为古诗词学习者设计：
1. **掌握平仄**：通过视觉化的平/仄标注和错误解释理解近体诗格律
2. **熟悉词牌**：通过不同关卡体验五绝、七绝等常见词牌的结构特点
3. **背诵记忆**：在拼接过程中自然记忆名篇名句
4. **意象理解**：通过关卡设计体会"月""山""花""酒"等古典意象
5. **寓教于乐**：分数、星级、连击等游戏化元素提升学习动力
