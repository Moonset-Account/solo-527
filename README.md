# 医院检验样本时效看板

面向检验科主任的检验样本全流程时效监控与分析系统。

## 功能特性

### 核心功能
- ✅ **全流程时效监控**：采样→送检→接收→检测→复核→报告发布，6个环节全链路追踪
- ✅ **急诊/常规样本分开统计**：不同优先级样本独立阈值和展示
- ✅ **箱线图分析**：各环节耗时分布可视化，识别异常值
- ✅ **超时阈值配置**：按样本类型×优先级×环节三维度设置阈值
- ✅ **科室对比**：样本量、超时率、退回率多维度科室对比
- ✅ **异常样本下钻**：点击异常样本查看详细时间线和退回原因
- ✅ **报告退回追踪**：记录退回原因、责任科室、退回人
- ✅ **趋势分析**：按日/周/月查看时效变化趋势
- ✅ **Excel 报告导出**：包含时间窗口、样本量、筛选口径的完整报告

### 数据处理特性
- ✅ **时间戳清洗**：自动校验时间顺序，异常值处理
- ✅ **补录标记**：source 字段区分自动采集/人工补录，补录不覆盖真实时间
- ✅ **超时原因分析**：关联退回记录，识别超时根因

## 技术栈
- **前端可视化**：Python Dash + Plotly + Dash Bootstrap Components
- **数据库**：TimescaleDB (基于 PostgreSQL 的时序数据库)
- **数据处理**：Pandas + NumPy
- **导出**：OpenPyXL + XlsxWriter

## 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 配置环境变量
复制 `.env.example` 为 `.env` 并根据实际情况修改：
```bash
cp .env.example .env
```

**默认使用模拟数据模式**（`USE_MOCK_DATA=True`），无需配置数据库即可运行。

### 3. 运行应用
```bash
python app.py
```

访问 http://localhost:8050 查看看板。

## 功能模块说明

### 1. 时效概览
- KPI 卡片：总样本数、超时样本、退回样本、平均总耗时
- 各环节平均耗时柱状图（急诊/常规分组对比）
- 样本优先级分布饼图
- 各环节超时率统计

### 2. 箱线图分析
- 各环节耗时分布箱线图（支持按样本类型筛选）
- 详细统计指标：平均值、中位数、P25/P75/P95 分位数

### 3. 科室对比
- 散点图：样本量 vs 超时率（气泡大小表示样本量）
- 科室时效排名表：样本量、平均耗时、超时率、退回率

### 4. 超时与退回
- 退回原因分布条形图
- 异常样本列表（支持点击下钻）
- 样本详情模态框：基本信息、各环节时间（含补录标记）、时间线甘特图、退回记录

### 5. 趋势分析
- 平均总耗时与超时率双轴趋势图
- 支持按日/周/月聚合

### 6. 阈值配置
- 可编辑表格：按样本类型×优先级×环节配置超时阈值（分钟）
- 修改后实时生效

### 7. 报告导出
- 点击「导出报告」按钮下载 Excel 文件
- 报告包含 6 个 Sheet：
  1. **报告概览**：时间窗口、样本量统计、筛选口径说明
  2. **样本明细**：所有样本的详细数据
  3. **超时统计**：各环节超时情况汇总
  4. **科室对比**：各科室时效指标
  5. **退回记录**：所有退回样本的详细记录
  6. **阈值配置**：当前生效的超时阈值

## 数据库配置（可选）

如需连接真实的 TimescaleDB 数据库：

1. 将 `.env` 中 `USE_MOCK_DATA` 改为 `False`
2. 配置正确的数据库连接信息
3. 执行 schema 初始化：
```bash
psql -U postgres -d lab_timeline -f src/database/schema.sql
```

## 样本检验流程

```
采样(collected_at) → 送检(dispatched_at) → 接收(received_at) → 检测(tested_at) → 复核(reviewed_at) → 报告发布(reported_at)
```

每个时间点都有对应的 `source` 字段：
- `auto`: 系统自动采集的真实时间
- `manual`: 人工补录时间（不会覆盖真实发生时间）

- 免疫 (immunology)

## 常见问题

**Q: 如何修改超时阈值？**
A: 进入「阈值配置」标签页，直接点击「阈值(分钟)」列的数值进行编辑，修改后自动保存。

**Q: 为什么有些时间标有「补录」标记？**
A: 表示该时间戳是人工补录的，不是系统自动采集的真实发生时间。补录时间不会覆盖原始真实时间。

**Q: 导出报告包含哪些内容？**
A: 导出的 Excel 报告完整记录了当前筛选条件下的所有数据，包括概览、明细、统计、退回记录和阈值配置，便于离线分析和汇报。
